# 报告归档（archive）

存放**非日更序列**的报告：代码修复后重生成的预览、手动重跑的对比版、被新代码取代的旧版等。

**为什么单独放**：`data/reports/` 根目录是 launchd 每日自动生成的正式序列（`<sym>_<YYYY-MM-DD>.html`，日期＝真实交易 session）。幂等/趋势逻辑（`scripts/daily_update.sh`、`outlook_scores.json`）都按根目录的日期序列走。重生成的预览若落在根目录、用了非真实交易日的日期（周末/重跑日），会污染序列。归档到此处即可保留、又不干扰。

**命名约定**：`<sym>_<数据日>data_<原因>_<生成日>.html`
例：`silver_2026-08-15data_regen-after-flowfix_2026-08-17.html`
＝用 08-15 快照数据（周五 8/14 session）、在 flow 层绝对 IV 闸门 + 综合层双周期修复后、于 08-17 重生成的白银预览。

这些文件仅供人工查阅/留痕，不参与任何自动流程。
