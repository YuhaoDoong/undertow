## 组合保证金（Portfolio Margin）只支持两种场景

官方原文：

> 长桥目前支持在持有正股股票多仓的情况下卖出看涨期权（Covered Call），
> 或者持有正股股票空仓的情况下卖出看跌期权（Covered Put）两种组合。

即：

| 组合 | 是否减免保证金 |
|---|---|
| Covered Call（持股 + 卖 call） | ✅ 减免 |
| Covered Put（空股 + 卖 put） | ✅ 减免 |
| **垂直价差（vertical spread）** | ❌ **不减免** |
| **铁鹰（iron condor）** | ❌ **不减免** |

## 对策略的直接影响

### 铁鹰在长桥收两份保证金

铁鹰 = 卖 put 价差 + 卖 call 价差。价格不可能同时跌破 put 腿又涨破 call 腿，
所以标准做法只为其中一边留保证金 —— **这正是铁鹰存在的理由**。
长桥不认这个组合，两个价差各收一份，铁鹰退化成"分别做两笔单边"。

实测影响（SLV，DTE 4，宽 3 档，卖在墙上）：

```
              权利金    占用     年化
铁鹰·标准1份   $21.5    $164   +197%
铁鹰·长桥2份   $21.5    $302   +107%   ← 腰斩
```

### 但铁鹰不如单边的主因不是保证金

```
只做 put      +477%
铁鹰·标准     +197%   （单边 put 的 41%）
铁鹰·长桥     +107%   （单边 put 的 22%）
```

即便按标准一份保证金，铁鹰也只有单边 put 的 41%。
因为**铁鹰 = 赚钱那边的利润拿去补亏钱那边**：
样本期 SLV +9.7%，call 腿必然挨打（DTE 7：put +$11.5 vs call −$18.2）。

铁鹰买的是"不需要判断方向"。在有选墙规则与破墙平仓规则的前提下，
这个保险不值得付两份保证金去买。

## API 能拿到什么

`fetch_assets()` 只返回总量，**没有逐笔保证金明细**：

```python
AccountAssets(buy_power=..., net_assets=..., cash_by_ccy={...})
```

所以策略侧的占用估算只能自己算：**价差占用 = 宽度 − 权利金**（单边一份）。
铁鹰按两份相加。无法从 API 反查券商实际扣了多少，
若发现实际占用与估算不符，以券商为准并回来修正本文。
