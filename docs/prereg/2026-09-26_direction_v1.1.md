## 1. 定义（与 v1 相同，摘要）

- **Y：** v5 主终点 `pre_expiry_exit_policy` 的「净损益 ÷ 事前最大风险」，区间值按 v5 规则计算。
  - 配对差为 [x下界 − y上界, x上界 − y下界]。
  - 任一下界未知，这一对记为无界。
- **A：** 墙选腿（local_max，≤14 天，±5% 带内）。
- **B1：** `pick_b(mult=1.0)`，同美元宽度。它**不是**与墙同距离的对照。
- **方向信号：** `decision.flow.call_direction`。
  - 映射 dir-map-v1：偏多 → a=P，偏空 → a=C。
  - 其余为无方向，只进分母。
- **H-dir** = Y(B1,a) − Y(B1,o)。
- **H-wall|dir** = Y(A,a) − Y(B1,a)。
- 七个 ETF 品种分别检验。

## 2. 机会表（D02）

**范围：** 2026-09-28 至运行日的每个 NYSE 交易日 × 每个品种。正式运行时截到 2026-12-31。

每一格按下列顺序判定，归入且只归入一类：

| 类别 | 含义 |
|---|---|
| not_generated | 当天没有机会行（采集没跑或失败） |
| identity_fail | 准入不通过，原因分别计数（§0 D01） |
| no_direction | 身份合格但方向为中性或缺失 |
| no_candidate | 该假设需要的两条腿有任一不是候选 |
| beyond_formal_date | 仅正式运行：所需腿的到期日晚于检验日 |
| immature | 结果未出，且未过退出日（到期前最后交易日） |
| matured_missing_result | 已过退出日，但仍无结算结果 |
| entry_missing | 入场窗没有有效报价 |
| unpriced | 其余拿不到上界的情况 |
| unbounded | 两腿都有值，但有下界未知 |
| complete | 两腿都有界 |

**可配对率** = (complete + unbounded) ÷ (matured_missing_result + entry_missing + unpriced + unbounded + complete)。

分母的含义是「有方向、身份合格、已成熟、有候选的机会」。not_generated 和 identity_fail 不进这个分母，但必须随结论一起列出。它们属于工程失败，大量出现时先修数据链路。

## 3. 判定（每个品种、每项假设）

单侧 α = 0.05/14，沿用 v5 的日历块 bootstrap。前三步依次检查：

| 顺序 | 条件 | 判定 |
|---|---|---|
| 1a | 可配对率分母为 0 | 证据不足（尚无已成熟、可评估的机会） |
| 1b | 可配对率 < 0.5 | 证据不足（可配对率低于设计门槛） |
| 2 | 存在无界配对 | 未决（残腿处置未知） |
| 3 | 有配对的日期 < 20 | 证据不足（配对日期不足） |

通过这三步后，按区间判定：

| 条件 | 判定 |
|---|---|
| 下界 > δ | 支持（校正后下界超过经济门槛） |
| 上界 ≤ 0 | 不支持（校正后上界 ≤ 0） |
| 0 < 下界，且上界 < δ | 统计为正，但排除实用增量 |
| 下界 ≤ 0 < 上界 < δ | 排除实用增量（校正后上界 < 经济门槛） |
| 0 < 下界 ≤ δ ≤ 上界 | 统计为正，尚未证实超过经济门槛 |
| 其余 | 未决 |

**重要：** 20 日、0.5、δ=0.03 都是研究设计选择，**不保证统计功效**。「未证实」不等于「已排除」；只有上界 < δ 才能说排除了实用增量。

## 4. 描述性内容（不参与判定）

- **交互：** [Y(A,a)−Y(B1,a)] − [Y(A,o)−Y(B1,o)]，区间传播，有无界则计数。
- **共同样本（D03）：** 对 B1 和 A 各做一组。只取该规则两侧都是点值的日期，在同一组键上并列四项：顺向、逆向、总是卖 put、总是卖 call。每项给均值、胜率、最差 10% 均值及其点数，并输出键列表。
- **全机会：** 四个格子（B1/A × 顺/逆）各自的点值，区间和无界只计数。各格样本不同，不可互相比较。
- **直接做方向：** 顺向 B1 腿在入场窗、退出窗**实际采用的那次报价**所记录的标的价，看变动符号是否与方向一致。
- **dir-diagnostics-v1（Codex 011 允许的描述性诊断）：** 取 d=+1（偏多）或 −1（偏空），标的价同样对齐到实际采用的报价尝试。
  - `pre_move_ATR` = d × (入场标的价 − 决策价) / ATR14
  - `post_move_ATR` = d × (退出标的价 − 入场标的价) / ATR14
  - 「前收盘 → 信号可用」和「信号可用 → 入场」两段，因为信号可用时刻没有标的价，记为未知。pre_move 是这两段之和，不能全算成信号出来后错过的行情。
  - 只看信息发生在哪一段，**不据此过滤、不选阈值**。

## 5. 12/31 之后怎么说「墙」（更正 v1 回信的措辞）

v1 回信写的是「满足三条就放弃墙」。更正如下：

- **现有证据下优先采用 B1：** H-dir 判为支持或「统计为正」，同时 H-wall|dir 未判为支持。这时说「当前证据下优先采用 B1 的距离规则」，**不说「墙已被证伪」**。
- **正式排除墙的实用增量：** 只有 H-wall|dir 的校正后上界 < δ 时才能这样说。
- **尾部用途不能事后追认：** 若墙不改善均值、只改善尾部，不能事后改称「墙的风险用途」，要用新的预登记把尾部作为主目标重新检验。

## 6. 同距离对照臂（只设计，不启用）

Codex 011 指出，**同一侧、同一到期、与 A 同距离的非墙行权价在几何上不存在**，因为同距离就是同一个行权价。可选的设计有两种，都留给将来单独的研究版本，现在不启用、不计算：

- **近邻非墙档：** 取 A 两侧相邻挂牌档中 OI 较低的一档。距离差不超过一个行权价间隔，报告时列出这个距离差。
- **跨日期匹配：** 在同品种的其它日期里，找「A 所在 ATR 距离」相近、但该档不是局部 OI 最大的机会作对照。它引入日期差异，只能作为弱对照。

两者都会改变选腿，不能事后并入 v5，也不能事后并入本分析。
