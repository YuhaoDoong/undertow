## 2. 分层与基准的边界（全部写进代码常量）

- **regime：**S−1 收盘 ≥ 200 日均线（含恰好相等）记 up，否则记 down。有效收盘不足 200 个，或窗口内有缺失，记 None，**该日不参与分析**，并报告这类日子的数量。
- **季度：**按入组 session 的日历季度，不是收益终点所在的季度。
- **可用日：**正式记录身份与质量都合格，r 已按日历终点成熟，regime 已知，s 已知（−1、0、+1）。s 为 None 的日子既不算事件，也不算对照。
- **μ_k：**层内全部可用日（**包含**事件日）的 r 均值。冻结后不得改成非事件均值去挑显著。
- **共同支持：**层内至少 1 个事件，且非事件可用日 ≥ `MIN_NONEVENT_DAYS = 5`（固定设计选择，未校准）。不满足的层整层排除，排除的层数与事件数都要报告。
- **权重：**各层按事件数 n_k 加权，即每个事件等权。
- **不重叠：**在原始时间轴上固定事件资格：同一品种与上一个保留事件相隔 ≥ h 个交易日。重抽时**不重新筛选**。

## 3. 判定（唯一顺序；`direction_stats.judge`）

1. 固定事件资格。
2. **只数最终可比事件**：少于门槛时直接判 insufficient，**不计算任何收益统计**。conviction H1 的门槛为 30；skew 六项见附录 2。
3. 计算点估计 D_reg。
4. **重抽：**在完整交易日轴上做循环移动块 bootstrap，同一日的全部品种、事件与对照一起抽，空事件日也保留在轴上；每次重抽都重算 μ_k。
   - 块长：1 日与 5 日终点取 10，10 日终点取 20。
   - 块长 5 与 20 只报告，不能挑选。
   - 重抽 10000 次，种子 20260928。
   - 没有任何合格层的重抽记为无效；无效比例超过 5%，判为 insufficient。
5. 报告 q_α 下界、双侧 95% 区间、各项诊断。
6. q_α > 0 判为 detected，否则判为 not_detected。not_detected 要报告区间，不写成「无效」。
