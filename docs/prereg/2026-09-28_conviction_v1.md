## 2. 三层定义（全部复用现有常量，未新增阈值的地方注明）

对每个（品种，认证交易日 S），取认证到 S 与认证到 S 前一交易日的两份快照：用 `dirledger_cli.session_index`，按 captured_at 认证交易日。计算用 `analyze_flow` 与 `structure_read.analyze_structure`，today 取 S 前一交易日（即数据日）。

- **S 层（曲面）：**用 fa.vol 同一到期的 Δskew25（put−call）。
  - ≤ −0.50pp 记 +1，即转向 call，看涨；
  - ≥ +0.50pp 记 −1，即转向 put，看跌；
  - 其余记 0。
  - 门槛取现有常量 `structure_read.SKEW_SIG_PP`。
- **F 层（具体行权价）：**只用 `grade_leg` 判为可用的腿（可靠度「中」：增仓、相对 IV 与 Delta 修正同向、纯净度正常），且行权价在 spot ±5% 以内。
  - 权重为 |ΔOI × Δ|。
  - 看涨侧 = 买 call + 卖 put，看跌侧 = 买 put + 卖 call（AGENTS.md 期权流规则 2）。
  - 一侧权重大于另一侧的 2 倍、且大于 0 时，记该侧方向，否则记 0。
  - **±5% 与 2 倍是本版新定的门槛，未校准。**±5% 沿用 structure_read 的「近价保护」口径；2 倍请 Codex 审。
- **V 层（ATM IV 顺向扩张）：**ΔATM ≥ +0.30pp（现有常量 `SIG_PP`）时，记数据日收益的符号，即价跌而 IV 升记 −1、价涨而 IV 升记 +1；否则记 0。
  - 数据日收益为 S 前一交易日收盘 ÷ 再前一交易日收盘 − 1，信号发出前已知。

## 3. 假设

- **H1（两层同向，主假设）：**S = F ≠ 0，且 V ∈ {0, S}。按 S 的方向计分。
- **H2（ATM IV 顺向的增量）：**在 H1 事件内部，V = S 的事件（三层都齐）命中率高于 V = 0 的事件。这对应发现集里「缺 IV 顺向就失败」的观察。
- **H3（偏斜翻号，skewflip-v1）：**近月主力到期（`read_vol` 口径）的 10Δ 或 25Δ 偏斜水平变号，且此前连续 ≥ 10 个认证交易日在另一侧。
  - 翻到 put 贵（由负转正）记看跌，翻到 call 贵记看涨。
  - 10 日是本版新定、未校准的门槛。
  - 同一次翻号只计一次；10Δ 与 25Δ 在 5 日内相继翻号，合并为一个事件。

## 4. 结果与计分

- **基准：**S 当日开盘价（`skew_reading.forward_returns`，与方向台账同一口径）。
- **结果：**1 日与 5 日收益的方向。主结果是 5 日；1 日只作描述。
- **不重叠：**同一品种相邻事件间隔不足 5 个交易日时，只保留第一个，并报告被剔除的数量。
- **对照：**同品种、同期所有认证交易日的上涨率。命中基准按事件方向构成计算（`structure_replay.score` 口径），不用 50%。
