# 设计草案 v0.2（开发期，未冻结，未计分）：方向信号选侧对卖方价差的增量

v0、v0.1 原样保留。本文件按 Codex 020 修订；**不阻塞**方向台账族 D 的正式起点。

1. **两侧都要满足时序：**
   - P、C 两侧都须满足：信号可得时刻（正式记录的 recorded_at）≤ 该侧入场报价的可得时刻（采样时刻）。只检查所选一侧不够。
   - 入场桶的选择与方向无关，固定为「09:45 起第一个两侧都有有效报价的桶」。
   - 两侧入场报价的采样时间差 ≤ 15 分钟（开发期设计值，未校准），超过就标为「不可比」。
   - 以上逐条写成断言，不依赖「一般时间表」。
   - 同时记录采样时刻、报价自身的时间戳与延迟。报价只说明「观测到」，不代表能按此成交。
2. **唯一主信号：**冻结后的 conviction H1。skew-v1 只作描述，不当第二个主检验，所以这一族只有一项主检验，单侧 α = 0.05。
3. **结论强度，二选一，选定前者：**
   - 采用「下界 > 0 且点估计 ≥ δ\*」。通过时，结论写作「检出正增量，点估计达到实用门槛」，**不写成**「在置信意义上改善至少 δ\*」。
   - 如果要作后一种声明，须另行预登记「下界 > δ\*」这一更强的检验。
4. **δ\* 与约束：**
   - 由开发期**只看入场时刻**的报价材料给出：报价宽度、两侧采样时差、费用占权利金的比例。
   - 得到的是**在一组假设下的敏感性范围**，不是成交误差的严格上界。
   - 缺价率是概率，不能直接当作 R 单位的损失加进去，只用来报告覆盖。
   - 不读任何结算结果。
   - 最低有效日期数、尾部约束、资金约束，与 δ\* 一起在开发期结束时冻结。
