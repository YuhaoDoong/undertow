# skew-reading-v1 附录 2（运行前修订）：六项主检验的计算合同（Codex 020-03）

原预登记与附录 1 原样保留。本附录**取代**原 §5 的检验方法；α 族（0.05/7）沿用附录 1。

## 为什么改

原 §5 用「该期间同方向的无条件基准」做二项检验。这个基准是从同一批市场收益里估计出来的，本身有误差；5 日、10 日窗口与对照之间还有时序依赖。把它当成已知、固定的 p0 来做二项检验不成立。加更多 Bonferroni 校正也修不好这个底层问题。

截至本附录，前瞻 eligible 记录只有 2026-09-28 一行，还没有成熟，**没有任何结果被看过**。

## 新方法（与 conviction 同一个计算器 `analyze/direction_stats.py`）

- **每项主检验：**黄金、白银，各取 h ∈ {1, 5, 10}。
- **事件：**v2 前瞻正式记录中 status = eligible 的读数。防守化记 s = −1，进攻化记 s = +1；中性记 s = 0，作对照；数据不足记 s = None，不纳入。
- **r：**session 开盘价到第 h 个交易日收盘（按日历确定终点）。收益恰为 0 时照常计入，不另行处理。
- **统计量：**D_reg，分层同 conviction v1.3 §2，只是品种固定为单一 ETF。事件资格在原始时间轴上按 h 固定不重叠。
- **推断：**`judge(rows, h, min_events=50)`。块长 1 日、5 日为 10，10 日为 20；q_α 下界，α = 0.05/7；无效重抽超过 5% 判为 insufficient。

## 触发与判定时点（二选一，选定为「共同固定日」）

- **不再用**「各期限各自达到 n ≥ 50 就各自判定」。改为六项与 conviction H1 **同日**一次判定：
  - 最后入组日 2027-03-31；
  - 先只数每项的最终可比事件数，门槛 **50**，沿用 AGENTS 的 MIN_N；
  - 不足的项，在看收益之前延期一次，到 2027-09-30；仍不足，判为 insufficient。
- **如实预告：**5 日、10 日的不重叠事件到 2027 年很可能达不到 50，这两类大概率会是 insufficient。这是样本约束，不会因此降低门槛。
