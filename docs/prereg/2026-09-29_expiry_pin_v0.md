## 2. 流动性描述的要点（6/25 以来的认证快照）

- **单个到期的总持仓：**月度远大于其余类型。GLD 约 60 万张，是周度（约 12–14 万）的 4–5 倍；季度约 15–19 万；日度约 1–2.5 万。SLV、QQQ、SPY 同样如此。
- **近平值的相对买卖价差：**剩余天数相同时，各类型差别不大。价差主要随 DTE 变化（0–2 天约 8–10%，22–45 天约 3–4%，指 GLD / SLV）。
- **成交量 ÷ 持仓量：**周度和日度远高于月度和季度。例如 GLD 在 0–2 天到期时，D 为 1.37、W 为 0.42，而 M 为 0.18、Q 为 0.21。
- **解读：**用户说月度、季度「更厚」，在持仓量上成立；说「流动性更高」，在报价松紧上不成立。更准确的说法是：月度、季度多为**持有不动的仓位**，周度、日度多为**短线进出**。
- 季度样本只有 6/30 一个到期（各 DTE 档的 n 只有 2–16），不能下结论。

## 3. 两个待讨论的问题

### P1 到期日磁吸

- **K\*_E：**该到期 E 自己的最大 OI 行权价，取现价 ±10% 内、C 与 P 合并。数据取自认证到 E 当日的快照，即 E−1 收盘结算的 OI，开盘前可得。
- **统计量：**当日「向墙靠拢量」 pull = (|open_E − K\*| − |close_E − K\*|) / ATR14。正值表示收盘比开盘更靠近 K\*。
- **对照（安慰剂）：**非到期日，用下一个到期的 K\* 计算同样的 pull；同一品种、同一时期。
- **问题：**
  - 到期日的 pull 是否大于非到期日？
  - Q / M 是否大于 W / D？
- **样本：**
  - 探索：6/25–9/25 的历史，7 个 ETF 加 TQQQ。M 有 7/17、8/21、9/18，Q 只有 6/30，W / D 有几十个。
  - 前瞻：9/30 起的 `expiry_profile` 记录。

### P2 墙的权重（回应用户「不同标签权重可以不同」）

有三种互相竞争的墙定义，只比较、不预先择优：

| 代号 | 定义 | 背后的逻辑 |
|---|---|---|
| W0 | 现行定义：≤14 天所有到期的 OI 按行权价加总取最大 | 现状 |
| W1 | 最近一个 M / Q 大到期自己的最大 OI 行权价 | 用户：月度 / 季度更厚，是「有人守」的价位 |
| W3 | Σ\|Γ\|×OI（gamma 加权，逐合约使用快照自带的 gamma） | 对冲压力：临近到期、价格附近的合约每张影响大；没有自由参数 |

- **比较方式：**比较三者对「持有期内收盘位置 / 破墙」的描述能力，用同一套 v5 口径的 3 收盘破墙率，加上到期日的 pull。
- **原则：**不在历史上挑权重数值（例如「月度 ×2」）。类型只用来**分层报告**，不当作权重。若要赋予权重，只能先预登记一个版本，再用前瞻检验。
- **理由：**类型权重有自由参数，历史只有约 3 个月、1 个季度到期，挑出来的数值必然过拟合。gamma 加权没有自由参数，但有一个前提：它**不知道做市商持有哪一侧**。这是它的局限。

## 4. 已知局限

- **结算时点：**ETF 期权在收盘后按收盘价结算（PM 结算、实物交割），磁吸若存在，应体现在收盘价上。
- **盘中 OI 未知：**快照 OI 是 E−1 收盘时的，E 当日盘中的开平仓看不到。
- **样本太少：**季度样本太少。9/30 是第二个季度到期，下一个是 12/31。
- **9/30 这一单例：**用户对 9/30 的猜测（金银被拉回 380 / 55 附近）只是一个单例，只作记录，不能证明或否定磁吸。
- **价格数据：**需要 E 当日的开盘价与收盘价（长桥日线；CBOE 日线会滞后）。
