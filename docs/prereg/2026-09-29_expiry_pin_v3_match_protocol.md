# 到期日磁吸 v3：同品种事前匹配对照协议（探索，已看过 v1/v2 结果；不进入冻结方向族或 v5）

**写定：** 2026-09-29（Codex 027 §四定范围，Claude 实施）。本文在计算任何配对结果**之前**提交；实现只能照此执行，
改动任何字段、分箱或窗口都是新版本。v1（`expiry_pin_explore_20260929.*`）与 v2（`data/backtest/expiry_pin/expiry-pin-explore-v2-…`）保留。

## 1. 主张范围

同一品种可比较的日期上，到期日相对非到期日，「朝事前选定墙靠近量」是否不同。
- 这仍把到期身份与 DTE 等差异包含在内，**匹配不等于识别了纯到期因果效应**。
- 这是看过历史之后的探索，**不是**检验；成功只意味着方法可复核，策略成功仍需未来独立样本及净收益、尾损验证。

## 2. 样本与字段（全部用 D−1 收盘时已知的信息；开盘价不算盘前已知）

- **历史范围固定** 2026-06-25 至 2026-09-25（按认证交易日）；不自动吸入 9/29 起的前瞻数据。
- **品种精确匹配**：QQQ 与 TQQQ 不互充对照；不具备「到期日」和「非到期日」两种日期的品种，仅在本对照中剔除，并在输出中列明，不写成「无效」。
- **到期日**：D 为该品种某个挂牌到期的当天。**墙 K**：D 起最近一个到期自身在 ±10% 内的最大 OI 行权价（C+P 合并），并列取离参考价近者，再取低者；OI 来自认证到 D 的快照（D−1 收盘结算）。这与 v1/v2 的 P1 定义相同。
- **参考价** `C[D−1]`：D 之前最后一个日线收盘。
- **方向**：K 相对 `C[D−1]` 为 above / below / equal。
- **墙距**：`|C[D−1] − K| / ATR14`，ATR14 只用 D 之前的日线；分箱沿用 0.5 / 1 / 2 ATR，即 [0,0.5)、[0.5,1)、[1,2)、≥2。
- **波动档**：`ATR14 / C[D−1]` 在 D 之前 60 个完整交易日同一序列中的经验三分位。分位点用 `statistics.quantiles(n=3, method="exclusive")`；不足 60 日则不匹配。
- **20 日趋势**：`sign(C[D−1] − C[D−21])`，取正 / 负 / 零。
- **事件**：高影响事件三态 known_high / known_none / unknown。本历史期没有当时可得的事件档案，所以**全部记 unknown**；unknown 只与 unknown 匹配，不当作「无事件」。
- **持有窗**：开盘至收盘。`pull = (|O − K| − |C − K|) / ATR14`，与 v1/v2 相同。开盘墙距 `|O − K| / ATR14` 只另外记录，不参与匹配。

## 3. 匹配

- 每个到期日只在**同品种**、前后 **20 个交易日**内，找以下字段全部相同的**非到期日**：方向、墙距箱、波动档、趋势符号、事件态。取时间最近的一个；距离相同时取日期较早者。
- 对照日可以重复使用，逐一记录使用次数。这里允许使用历史上位于未来的日期作研究对照，所以**不是**在线可执行的模型。
- 无对照的到期日记 unmatched，**不放宽**箱界，不跨品种凑样本。
- 共同支持：只有到期日与非到期日都出现过的「品种 × 方向 × 墙距箱 × 波动档 × 趋势 × 事件」格子，才能进入比较。

## 4. 输出（第一版不给 p 值、不给区间）

1. 共同支持表：每格的到期日数、非到期日数、已配对数；unmatched 清单及原因（字段不同、窗口内无对照、历史不足 60 日）。
2. 配对表（逐行）：品种、到期日与对照日、交易日间隔、对照复用次数，以及两边的 K、`C[D−1]`、O、C、ATR、墙距（参考价与开盘两种）、pull 和配对差 `pull_E − pull_N`；另列墙距余差 `|dist_E − dist_N|` 等残余不平衡。
3. 描述：每个品种与合并后的配对数、配对差均值与中位数、配对差为正的比例；一并报告对照复用的分布。
4. 若配对太少，如实写「本数据不能识别」，**不换统计量找正结果**。以后如果加区间，必须用同步时间块，并在重抽样内重做匹配。
5. d0/d1 只作辅助描述，不作独立证据。

## 5. 复现

`python3 scripts/expiry_pin_match.py --start 2026-06-25 --end 2026-09-25 --asof <日期>`。产物目录已存在则拒绝覆盖；保存日线原文和哈希、快照路径和哈希、代码哈希、git HEAD、逐行配对表。
