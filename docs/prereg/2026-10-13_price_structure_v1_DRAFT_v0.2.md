## 1. 假设

**主族（20 格，每格一个主统计程序，校正 α = 0.05/20）：**
- **H1（做多，先破后回）：** A 型事件（见 3.4）在 HL₁ 入场的 R 倍收益，高于事前状态匹配对照的 R 倍收益。
- **H3（做空，镜像）：** A 型做空事件在 LH₁ 入场的 R 倍收益，高于匹配对照。
- **H4L / H4S（10 交易日收盘屏障生存率增量）：** H1 / H3 事件入场后第 1–10 个交易日（入场日计第 1 日）内，收盘**未越过**结构失效位的比例，
  高于匹配对照在同一 ATR 距离屏障上的生存率。只用于判断「结构失效位是否比同距离普通价位更难被收盘越过」，**不是价差胜率**。
- 品种：GLD、SLV、USO、QQQ、SPY。H1、H3、H4L、H4S × 5 = 20 格。某格样本不足也不缩小分母。

**探索（不救主结果、不替换未通过的主格）：** H2 政策比较；H4 的 5 日版本；符号检验；m ∈ {1.5, 3.0}；目标 1.5R / 3R；年度基准；各品种清晰结构时间占比（描述）。

## 3. 状态机（全部确定性；同一输入与版本必须完全复现；只用历史前缀）

### 3.1 指标
- **ATR：** 14 日 Wilder，基于真实 OHLC。种子 = 前 14 根真实波幅的简单平均；此前不产生任何摆动点。在第 t 根 K 线上做判断时只用 ATR_{t−1}。
- **预热：** 每个品种从第 15 根起才开始之字形；检验集的指标可用此前历史预热，但设计集的持仓不得延续进检验集（见 §5.5）。
- **缺会话：** 交易日历上应有但数据缺失的会话 → 该品种从缺口起暂停状态机并记 `gap_pause`，恢复后重新预热 15 根，期间不产生事件（不插值）。

### 3.2 之字形（主规格：收盘极值、收盘反转，m = 2.0，未校准）
在第 t 根收盘后依次执行（顺序固定）：
1. **更新候选极值：** 下行腿中，若 C_t < 候选低 → 候选低 = C_t；上行腿镜像。**相等不替换**（相等时保留更早那根）。
2. **检查反转：** 下行腿中若 C_t ≥ 候选低 + m·ATR_{t−1} → 确认摆动低点：价格 = 候选低，`extreme_at` = 候选低所在日，`confirmed_at` = t；
   转入上行腿，新候选高 = (候选低日, t] 内最高收盘（相等取更早）。上行腿镜像。
3. **起始方向：** 预热后从第一根起同时跟踪最高收盘与最低收盘，先满足反转条件的一侧确定第一个摆动点。

### 3.3 结构状态与关键位
- **下降结构（regime = down）：** 最近两个已确认摆动高点依次下降，且最近两个已确认摆动低点依次下降时进入。进入后**保持**，直到下述突破发生（一个更高的低点不会解除它）。上涨结构镜像。
- **LL：** 下降结构中最近一个创新低的已确认摆动低点。**关键 LH：** `extreme_at` 早于 LL 的最近一个已确认摆动高点（即 LL 之前的那个更低高点）。
  LL 之后出现的较低摆动高点是「小 LH」，不是关键位。
- **第 t 根上的突破判断只用第 t−1 根收盘后已知的关键位**；第 t 根新确认的摆动点从第 t+1 根起才生效（防止同根确认改变关键位）。
- **突破（做多方向）：** regime = down 且 C_t > 关键 LH。突破时冻结：方向、关键 LH（价、`extreme_at`、`confirmed_at`）、LL（同）、突破日、ATR_{t−1}。
  突破后 regime 置为 `broken`，须重新出现两高两低依次下降才再次进入下降结构。

### 3.4 事件（episode）
- **A 型（先破后回）：** 突破时，LL 之后尚无高于 LL 的已确认摆动低点。突破后第一个 `extreme_at` 晚于突破日的已确认摆动低点：
  - 价 > LL → HL₁，信号日 = 其 `confirmed_at`；
  - 价 ≤ LL → episode 失败（`invalidated_new_low`）；
  - 等待期间任何收盘 < LL → 失败；
  - 自突破日起 60 个交易日内未确认 → `timeout_no_entry`（未校准，与持有期分开计数）。
  **突破之前形成、突破之后才确认的低点不算回踩**（`extreme_at` 必须晚于突破日）。
- **B 型（先回后破）：** 突破时，LL 之后已有一个高于 LL 的已确认摆动低点（第一个这样的点 = HL₁ᴮ）。突破后第一个 `extreme_at` 晚于突破日、且价 > HL₁ᴮ 的已确认摆动低点 = HL₂ → 信号；
  若该低点 ≤ HL₁ᴮ 或等待期间收盘 < HL₁ᴮ → 失败；60 日上限同上。
- **H3：** 全部镜像（上涨结构、跌破关键 HL、LH₁ / LH₂）。
- 同一突破只产生一个 episode，不重复入组。同品种多空 episode 时间重叠时打 `overlap_opposite` 审计标签；同向新 episode 出现在持仓期间 → 记录、标 `occupied`，不进主检验。

### 3.5 交易（主终点 R）
- **入场：** 信号日次日开盘 O_{s+1}。缺开盘价 → `no_open`，不入场。
- **止损：** A 型做多 = LL − 0.1·ATR_{s−1}（信号日 s 判断时可知的 ATR，入场后不追改）；B 型做多 = HL₁ᴮ − 0.1·ATR_{s−1}；做空镜像。
- **风险单位：** R = 入场 − 止损（做多）。R ≤ 0（开盘已在止损之下）→ `open_beyond_stop`，不入场，不产生负风险单位，不回填理想成交。
- **目标：** 入场 + 2R（做多）。最长持有 60 个交易日（入场日计第 1 日），到期按第 60 日收盘平仓。
- **逐日判定（入场日起）：**
  1. 开盘 ≤ 止损（做多）→ 按开盘价出场（跳空，亏损可超过 1R）；
  2. 同一根内最低 ≤ 止损且最高 ≥ 目标 → 记止损（日内先后未知，保守近似，报告中注明）；
  3. 最低 ≤ 止损 → 按止损价出场；
  4. 最高 ≥ 目标 → 按目标价出场（含开盘已跳过目标：按限价目标保守计，不按开盘价）；
  5. 否则续持。
- 每笔记录 R 倍收益 = (出场 − 入场) / R（做空镜像）。

### 3.6 H4 终点
入场日起第 1–10 个交易日的收盘中，任一收盘越过止损价（做多 = 低于）→ 屏障被越过；否则生存。与 3.5 的交易出场相互独立（交易已止损也照样观察满 10 日）。

### 3.7 合成验收（写代码后、跑任何真实数据前）
- **前缀不变性：** 对任意 as-of，只给历史前缀与给完整数据，截至 as-of 已产生的摆动点、episode、信号完全一致。
- 必须有唯一结果的合成用例：v0.1 草案里的两个道氏示例（80→112→96→118→105；80→95→88→108→99）及其做空镜像；等值极点；
  反转后重置候选；突破当天新确认的摆动点；突破前形成、突破后才确认的低点；开盘已越止损；持仓跳空穿止损；同根双触及；开盘跳过目标；
  缺会话暂停与重新预热；拆股前后（按比例调整与逐日更新给出相同信号）；60 日等待上限。

## 4. 匹配对照（主比较；全部变量入场前已知）

- **候选池：** 同品种、同方向；入场日 u 与事件入场日 t 相差不超过 250 个交易日（前后都可，这是统计对照，不是交易信号）；
  排除任何同假设事件的入场日本身。
- **匹配变量（u−1 收盘可知）：**
  - 趋势代理 T = (C_{u−1} − SMA50_{u−1}) / ATR14_{u−1}，三档：< −1、[−1, 1]、> 1（边界未校准）；
  - 波动分位 V = ATR14_{u−1}/C_{u−1} 在该品种前 500 个交易日分布中的分位，三档：[0, 1/3)、[1/3, 2/3)、[2/3, 1]。
  - 目的：区分「普通趋势 / 波动筛选」与「精细结构」—— 若事件优势只来自处于趋势中，匹配后应消失。
- **控制交易：** 自 u 次日开盘入场，止损距离 = 事件止损距离的 ATR 倍数 × ATR_{u−1}，目标 2R、60 日、同一套跳空 / 双触及规则（3.5），H4 同口径（3.6）。
- **选取：** 每个事件取同档候选中时间最近的至多 10 个（距离相同取更早）；每个控制日最多被 5 个事件复用；无匹配 → `unmatched`，计数并报告，不进匹配估计。
- **年度基准（描述性）：** 同品种、同日历年全部交易日按同规则模拟，只作「是否超过该年单边参与」的描述，不进主检验，不进入任何交易决策或参数选择。
- 年度基准与匹配对照结论分歧时**不择优**，只允许较窄的那个结论。

## 5. 统计附录

### 5.1 估计量
每格：Δ = 事件均值 −（每个事件的匹配控制均值）的均值。H1/H3 用 R 倍收益；H4 用生存指示（0/1）。

### 5.2 推断：事件与控制共同按日历区块重采样
- 对该品种检验期的交易日序列做**移动区块 bootstrap**：区块长度 60 个交易日（覆盖最长持有期），B = 4000，随机种子 20261013。
- 每个重采样样本 = 首尾相接的区块；入场日落在样本中的事件与候选控制日**一起**进入（区块重复则按重复次数计），**在样本内重新匹配**后计算 Δ*。
  不允许只抽事件、把控制均值固定不动。区块边缘的事件照常按其入场日归属；稀疏事件的区块可以没有事件（该次 Δ* 用其余事件计算；若整个样本无事件则记缺失并报告比例）。
- **区间：** Δ* 分布的单侧下界取第 0.05/20 = 0.25 百分位（校正后单侧 99.75%）。
- **结论规则：** 下界 > 0 → 「存在增量」；下界 > 研究目标（H1/H3 +0.15R，H4 +5pp）→ 「至少达到目标」；点估计达到目标且显著仍不等于证明真实效果超过目标。
- **敏感性（不参与结论）：** 区块长度 20 / 120；年度基准；不重新匹配的固定控制版本。

### 5.3 功效与最少样本
- 单格检验期合格事件 < 50 → 只报告描述（个案、分布），不做推断，结论为「证据不足」，不是「无效」。
- 设计集完成后，用设计集估计各格 Δ 的 bootstrap 标准误，计算最小可检测效应 MDE ≈ (z_{0.9975} + z_{0.80})·SE；
  若 MDE > 研究目标，冻结时如实标注「检验期功效不足」，检验结果不显著时只能写「不确定」。不因样本不足而延长检验期到显著。

### 5.4 依赖
同方向不重叠不等于独立；不同方向、控制与事件、相邻日期都可能相关。区块重采样是本研究处理依赖的唯一主方法，其它方法只作敏感性。

### 5.5 分期与边界
- **设计集：** 各品种上市至 2015-12-31。可以运行、查看、调试；不改第 3–5 节定义，要改就在进入检验集前发新版本并写明看到了什么。
- **检验集：** 2016-01-01 至 2025-12-31，只运行一次；**2026 单列为后续诊断**，不进主结论。
- 设计事件的完整 60 日窗口不得跨入检验期（跨界者从设计集剔除）；检验期末不足完整 60 日（及 10 日 H4）窗口的事件预先剔除并计数，不只保留提前盈利的交易。
- **未见性声明：** 我（实施者）未用 2016 年以后的数据选择本规则；但道氏结构是广为流传的方法，检验集称「历史保留集」，不称「完全未见」。
- 主检验只运行一次不等于禁止修 bug：若发现 bug，保留首次结果、版本与影响，披露重跑，不称仍是第一次。

## 7. 第二阶段（另行登记，本稿不启动）

第一阶段通过只支持「某规则在固定历史口径下有方向 / 屏障增量」。第二阶段另冻结：实际期权到期、选档、信用 / 宽度、点差与费用、退出、缺报价处理、
同一判断的配对反事实；拆成两项比较——同一入场机会 / 风险预算下「结构方向 vs 冻结基线方向」，同方向下「结构失效位选档 vs ATR 距离选档」。
用真实可得报价为所有候选留痕（含被门槛挡下的）。失效位不是天然安全的短腿位置；最终以扣费净收益与尾部风险判定，不把三层各自的胜率相乘。
已成交仓位不受本研究影响。
