# 检验草案 v4（待 Codex 审定，未冻结，未实现，未计分）：近价墙的到期收盘磁吸

**写定：** 2026-10-14，Claude Opus 5.5 起草。Codex 审定并冻结之前不写实现、不计算任何结果统计。
与 v0–v3 的关系：v0–v3（`docs/prereg/2026-09-29_expiry_pin_*`，`data/backtest/expiry_pin/`）只用 2026-06-25 至 09-25 的历史，
全部是「看过之后的探索」。本版是第一个**只用此前未被任何磁吸 / 墙位研究计算过的到期日**的检验。

## 0. 用户原话与动机

> 「正股走得少」，这已经隐含了，我们墙很安全，正股在墙内波动，没有突破墙。

> 看起来贴近现价的几次，也有很强的墙位对冲，收盘都是在墙位附近的

动机来自模拟仓已了结仓位的事后归因（明细私有，不入库）：卖腿贴近现价（≤1.2%）、卖在当期大持仓行权价上的几笔，
到期收盘大多落在卖腿所在的墙带内。按入场前 250 日、同持有天数的历史涨跌分布，15 笔里「了结时仍在卖腿有利一侧」
的期望约 9.2 笔，实际 13 笔；但 15 笔只来自 4 个判断日。
**已知污染：** 起草前我看过 GLD / SLV 的 2026-09-30 与 2026-10-05 两个到期（共 4 个品种 × 到期）的墙与收盘，见 §6 敏感性。

已有结论（不因本版改写）：S03「未检出墙的增量，也未排除」；v2 的 E−2 多日 diff 对同距离安慰剂 ≈ 0；
v3 GLD 配对 10/12 为正、SLV 5/16 为正，均为探索描述。

## 1. 主张（单一主终点）

对 GLD、SLV 的每个挂牌到期 E：在 E 之前 h 个交易日入场时已知的**近价局部墙** K\*，到期收盘 C_E 离它的距离，
是否比「同一零模型下、同侧同距离的非墙行权价」更近。

- 方向是单侧主张（墙更近 = 磁吸）；报告双侧区间。
- 这只是**收盘位置**的主张，不是策略净收益主张；净收益与尾损另由影子账 v5 前瞻处理。
- 检出不等于因果（做市商对冲方向未知、OI 不代表净头寸）。

## 2. 样本

- **主品种：** GLD、SLV（实际交易品种）。QQQ / SPY / IWM / TLT / TQQQ / USO 只作次要描述，不进主终点。
- **到期：** 链上实际挂牌的全部到期 E（Q / M / W / D 都要），E ∈ [2026-09-28, 2026-12-31]。
- **分两次看：**
  - 阶段一：E ≤ 2026-10-30，在 11/02 运行一次，**只作描述**，不下结论、不改规则；
  - 阶段二（主分析）：E ≤ 2026-12-31，在 2027-01-04 运行一次，区间与判定只在这里给。
- **入场时点：** S = E 之前第 h 个交易日，**主 h = 2**；h = 1、3 为次要。
- **信息集（全部为 S 开盘前已知）：**
  - OI：认证到 S 的期权快照（按 captured_at → decision_session，复用 `session_index`；即 S−1 收盘结算的 OI）；
  - 参考价：C[S−1]，取真实日线收盘，**不用 snapshot.spot**；
  - ATR14：只用 S−1 及以前的日线。
- **缺失：** S 没有认证快照、E 无日线收盘、链上无 E → 记 unmatched 并列原因，不补、不换日。

## 3. 定义

- **近价带：** |K − C[S−1]| ≤ 1.0 × ATR14。
- **墙 K\*：** 到期 E **自身**在近价带内 OI（C+P 合并）最大的行权价；并列时取离 C[S−1] 近者，再取低者。
  带内不足 3 个有 OI 的行权价 → unmatched。
  不设「主导度」门槛（避免拍阈值）；主导度 = OI(K\*) / 带内其余行权价 OI 中位数，只用于 §5 分层描述。
- **安慰剂 K_p：** 同一到期 E、与 K\* 在 C[S−1] 同侧（K\* 恰等于 C[S−1] 时两侧都可）、
  距离 |K_p − C[S−1]| 与 K\* 的距离相差 ≤ 0.25 ATR14、OI ≤ 0.5 × OI(K\*)、K_p ≠ K\* 的全部挂牌行权价。
  没有任何安慰剂 → unmatched（不放宽）。
- **零模型（无墙时 C_E 的分布）：** 用 S−1 之前 250 个交易日该品种自身的 (h+1) 日 ATR 标准化变动
  z_t = (C[t+h+1] − C[t]) / ATR14(t)（ATR14(t) 只用 t 及以前），生成 C_E 的经验分布 C[S−1] + z × ATR14(S−1)。
  窗口内 z 的计算不得用到 S−1 之后的价格。
- **距离分位：** u(K) = P_null(|C_E^null − K| ≤ |C_E − K|)。无磁吸且零模型校准时 u ~ U(0,1)；磁吸 → u 偏小。
- **行统计量：** d_E = u(K\*) − mean_p u(K_p)。用安慰剂相减，抵消零模型的整体校准误差（波动估错会同时影响两边）。

## 4. 主分析与判定

- 主统计量：GLD 与 SLV 合并的 mean(d_E)；同时按品种分别报告。
- 区间：按**日历周**分块的块 bootstrap（GLD 与 SLV 同周的行同进同出，相邻到期的持有窗重叠也在块内），
  10 000 次，种子写死 20261014；报告 95% 百分位区间。
- 判定（三选一，写死）：
  - 区间上界 < 0 → 「检出近价墙的收盘磁吸（描述性，非因果）」；
  - 区间下界 > 0 → 「收盘反而远离墙」；
  - 否则 → 「未检出，也未排除」。
- 最少样本：有效周块 < 8 → 只报「本数据不能识别」，不给区间。
- 不做多重比较之外的显著性挑选：主终点只有这一个，§5 全部是次要描述，不得用来替代主结论。

## 5. 次要（只描述，不判定）

1. **穿越校准：** 对每行记 cross(K) = C_E 是否越过 K（K 在上方 → C_E > K；在下方 → C_E < K），
   与零模型下的穿越概率 q(K) 比：Σcross − Σq，墙与安慰剂各一组。这是卖方关心的量（卖腿到期是否被穿）。
2. h = 1、h = 3 重复主统计量。
3. 按到期类型 Q / M / W / D 分层（`analyze/expiry_type.py`）。
4. 按主导度三分位分层（剂量反应描述）。
5. 次要品种逐个描述。
6. 墙距分箱 [0, 0.5)、[0.5, 1.0] ATR。

## 8. 已知局限

- 样本小：链上 GLD 每周约 5 个到期（日度）、SLV 约 3 个（一三五），三个月约 65 / 39 行，但相邻到期的 h=2 持有窗大量重叠，有效周块只有约 13；功效有限。
- 同周 GLD 与 SLV 高度相关，按周分块后实际独立信息约等于周数。
- OI 是 S−1 收盘的，S 到 E 之间的开平仓看不到；E 当天的 0DTE 变化完全看不到。
- 局部墙只是带内最大值，不代表做市商净 gamma 方向。
- 零模型假设近 250 日的波动结构适用于当下；安慰剂相减只抵消整体偏差，不抵消墙附近特有的波动差异。
