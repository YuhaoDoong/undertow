1. **独立周翻转的零假设写过了。** 原 §4 说「按周整体翻转得到的就是零分布」。实际需要的是**强零假设**：给定全部事前协变量

## 1. 主张（单一主终点）

对 GLD、SLV 的每个挂牌到期 E：在 E 之前 h 个交易日入场时已知的近价局部墙 K\*，到期收盘 C_E 是否离 K\* 比离它关于参考价的**镜像点**更近。

- 判定三选一：「收盘离墙比离镜像点近（描述性关联，非因果）」/「收盘反而离墙更远」/「未检出，也未排除」；数据不足 →「本数据不能识别」。
- 只是收盘位置的关联主张，不是策略净收益主张（净收益与尾损由影子账 v5 前瞻处理）。
- **检出 ≠ 磁吸因果：** 合成里把 OI 放在价格将要去的地方（知情押注、没有任何磁吸），检出率 100%（r1 `informed_wall_not_null`）。

## 3. 定义

- **近价带：** |K − r| ≤ 1.0 × ATR14（不变）。
- **墙 K\*：** 到期 E 自身在近价带内 OI（C+P 合并）最大的行权价；并列时取离 r 近者，再取低者。不设主导度门槛。
- **镜像点：** K_m = 2r − K\*（不需要是挂牌行权价，不需要 OI 条件 —— 因此不像同侧安慰剂那样排除低 ATR 日）。
- **side：** +1 = K\* > r，−1 = K\* < r，0 = K\* = r（这一行不提供信息，不进两侧均值，计数单独报告）。
- **主行统计量（核版）：** m_k = φ(C_E − K_m) − φ(C_E − K\*)，φ(x) = exp(−x² / 2(0.25·ATR14)²)。收盘贴近墙 → m_k ≈ −1。
  核宽 0.25 ATR 由纯合成功效比较定（核版对线性版：30% 拉力 52 周 72% 对 15%，r1），未用任何真实数据。
- **次要行统计量（线性版）：** m = (|C_E − K\*| − |C_E − K_m|) / ATR14；收盘恰在墙上时 m = −2|K\* − r|/ATR14（修订 2 更正）。
- **为什么不需要零模型：** 只要 C_E − r 的分布关于 0 对称，E[m_k] = E[m] = 0 恰好成立，与波动尺度、厚尾、零模型估多估少都无关。
  Codex 044 的反例（真实 U[−.5,.5]、错误零模型 U[−1,1]、K\* = .10）下旧 d = −.1025，镜像统计量均值为 0（测试 `test_codex_counterexample_old_d_negative_mirror_zero`）。
- **漂移：** 主统计量 = 墙在上方各行均值与墙在下方各行均值的**等权平均**（side_balanced_mean），一阶抵消线性漂移。任一侧没有行 →「本数据不能识别」。
- **权重：** 两侧之内按行等权；GLD 每周约 5 个到期、SLV 约 3 个，所以合并统计量里 GLD 行多于 SLV —— 这是按挂牌频率加权，不是两品种等权。分品种结果同时报告。
- **等于行权价：** 收盘恰等于 K\*（或 K_m）时 m_k 取极值、m 取 ∓2|K\*−r|/ATR（修订 2 更正，原写漏 2），自然处理；次要穿越分析里记「触及」，不算越过。

## 4. 主检验与判定

- **周级符号翻转随机化检验：** 行按决策日 S 的 ISO 周归周。零假设 = 价格增量关于 0 对称；把一整周的增量取反，该周每行的 C_E − r 同时取反、m_k 恰好变号、side 不变，
  所以按周整体翻转符号得到的就是零分布，周内任意相关（GLD/SLV 同日、同周多个到期的重叠窗口）都保留。
  统计量对周符号是线性的，周数 ≤ 16 时枚举全部 2^W 种；否则抽 20 000 次，种子 20261014（`pin_stat.signflip_test`）。
- **判定（写死）：** p_lower < 0.025 → 「收盘离墙比离镜像点近（描述性关联，非因果）」；p_upper < 0.025 →「收盘反而离墙更远」；否则「未检出，也未排除」。
- **最少样本：** 有效周 < 8 →「本数据不能识别」。
- **已知近似：** h = 2 时周一、周二决策的行，其持有窗含上周五的增量，会把相邻周轻微连在一起；r2 的合成（含这种重叠）显示假检出率仍在 1.5–3.5%（名义 2.5%）。
- 主终点只有这一个。§7 的次要分析不得替代或升级为主结论；pin 结果不好时，不能事后把穿越提为主终点。
- **不再用块 bootstrap 区间做判定：** r1 显示 13 周的循环块 bootstrap 百分位区间覆盖只有 0.87–0.93、假检出 3.5–7%（名义 2.5%），2 周块也没改善。只作描述性区间附带报告。

## 9. 已知局限

- 功效有限（§6）；相邻到期的持有窗大量重叠，有效信息约等于周数。
- 零假设是「增量对称」：持续单边趋势会让两侧不平衡时残留偏差（r2 漂移情景假检出 3.5%，在误差边缘），偏度大的品种亦然。
- OI 是 S−1 收盘的；S 到 E 之间、尤其 E 当天 0DTE 的开平仓看不到。局部墙只是带内 OI 最大，不代表做市商净 gamma 方向。
- 墙贴近参考价（side = 0 或 |K\* − r| 很小）的行不提供信息：检验对象是「偏离参考价的墙」。
- 核宽 0.25 ATR 与 1 ATR 近价带是设计选择，由合成定、未在真实数据上校准；冻结后不再改。
