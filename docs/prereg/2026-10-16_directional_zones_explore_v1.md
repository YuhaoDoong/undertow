## 1. 要检验的说法

外部作者二 2026-10-15 自述：做多和做空看的位置不同，向上看压力、向下看支撑，同一价位从哪边来意义不同。
他的附图（伦敦金日线）标了两个框，我们读作（**推断，作者本人没有给可操作定义**）：

- **R 区（向上时压力）：** 前一段下跌途中的第一段横盘整理区；
- **S 区（向下时支撑）：** 急涨段起涨那根大阳线的实体中段。

vp-v1 H1「到达密集区先反弹」不分来向，它的否定结果不覆盖这个说法。

## 2. 定义（全部参数未校准，看结果后不改；若改须写进 run 目录的研究决策日志）

- **数据：** 日线 OHLC（Yahoo，拆股已调整、未按分红调整）。OHLC 有缺的行剔除。ATR = Wilder 14 日（`price_structure.wilder_atr`）。
- **走势段：** 收盘之字形 m = 2·ATR（`price_structure.zigzag`，与 ps 路线同一实现）。相邻两个已确认摆动点构成一段；
  该段在终点摆动点的确认根（`conf`）收盘后才算已知。
- **R 区：** 对每个下跌段（H → L），从 H 的下一根起找**第一个** 5 根连续 K 线的窗口，满足：
  ① 窗口最高价 − 最低价 ≤ 1.5·ATR[窗口首根前一根]；② 窗口最高价 < H 的收盘价（在高点之下，算「途中」）；
  ③ L 的收盘价 ≤ 窗口最低价 − 1.0·ATR[窗口首根前一根]（之后又继续跌了至少 1 个 ATR，不是底部横盘）；④ 窗口完全在 L 之前。
  区间 = [窗口最低价, 窗口最高价]。没有满足条件的窗口 → 该段不产生 R 区。
- **S 区：** 对每个上涨段（L → H），找 L 之后（含 H）**第一根** 收盘 − 开盘 ≥ 1.0·ATR[前一根] 的阳线（起涨大阳线）。
  区间 = [开盘 + 0.25·实体, 开盘 + 0.75·实体]（实体中段）。没有这样的阳线 → 该段不算急涨、不产生 S 区。
- **启用：** 从该段终点的确认根（收盘后可知）起启用，记启用根 a。R 区要求 a 收盘 < 区间下沿（价格在下方、向上来），
  S 区要求 a 收盘 > 区间上沿；否则记 `crossed_before`，不算事件。
- **触及：** 启用后 120 个交易日内第一次触及：R 区 = 最高价 ≥ 下沿；S 区 = 最低价 ≤ 上沿。未触及 → `no_touch`。
- **结果（首次通过，收盘判定，触及根起含当根，最多 20 根）：** 尺度 A = ATR[触及根前一根]。
  - R 区：收盘 ≤ 下沿 − 1.5·A → `reversed`（压力有效）；收盘 ≥ 上沿 + 0.5·A → `broken`（被突破）；
  - S 区：收盘 ≥ 上沿 + 1.5·A → `reversed`（支撑有效）；收盘 ≤ 下沿 − 0.5·A → `broken`；
  - 20 根内都没有 → `none`；数据不足 20 根且未判定 → `incomplete`（不计）。
  - 另报 10 日带符号位移：(收盘[触及+10] − 迎面沿) / A，R 区取负号（向下为正）。
- **去重：** 同一品种、同一类区间，触及根相距不足 5 个交易日的只保留第一个。
- **安慰剂对照（基线）：** 每个真实区间配两个同宽、同时刻启用、同来向的假区间，整体平移 ±2·ATR[启用根]，用完全相同的启用/触及/结果规则计算。
  它衡量「随便画一个同宽、同距离附近的框，价格碰到后掉头的比例」。

## 3. 检验与报告

- **主指标：** 掉头率 = reversed / (reversed + broken + none)。
- **对比：** 每个真实事件的 成功(0/1) − 其有效安慰剂成功率的平均 → 配对差；报告均值、t 值与符号检验双尾 p。
- **品种：** GC=F、SI=F、USO 为主检验（2 类区间 × 3 品种 = 6 个检验，Bonferroni α = 0.05/6 ≈ 0.0083）；
  GLD、SLV 与 GC=F、SI=F 是同一标的，只作重复核对，不计入、不与期货合并。
- **分层（事前可知）：** 启用根 200 日均线相对 20 根前上升 / 下降，分开报告，只作描述。
- **敏感性（事先列明）：** 掉头门槛 1.0·A 与 2.0·A 各跑一次，只作描述。
- **门槛：** 掉头率 Wilson 下界、配对差为正且过 Bonferroni、各品种方向一致，才说「设计期支持」；即便如此仍只是探索，
  要在 2016 年起的确认集、经 Codex 审定后才可能升级。

## 4. 已知局限

- 定义是我们从一张附图和几句话里读出来的，作者本人的「有效价格区间」没有可操作定义，检验的是我们的读法、不是他本人的判断能力。
- 他实际用伦敦金/银现货 CFD 与布伦特；这里用 COMEX 连续合约（换月有机械跳空，未调整）与 USO（原油弱代理）。
- 设计期（2000–2015）只有一种数据源、一段历史；不同区间可能相互重叠，配对差按事件计，同一时期的多个事件不完全独立。
- 只检验「碰到区间后先掉头」，不检验他在框外给出的具体价位（那些在 `author_levels` 前瞻台账里逐条计分）。
