## 1. 为什么修订：v1 causal 有前视

v1 的 causal 先对**全部历史**做分形点交替投影（`alternating(fractal_pivots(全部 bars))`），再在这个**最终投影**上找楔形，
只把最后一个摆动点的确认根当作「认出根」。但交替投影会让后来更极端的同类点取代此前的末端点：
一个在当时已经成立、已经认出、甚至已经突破的楔形，会因为未来某个点取代了它的端点而**从结果里消失**。
确认滞后只处理了「点要等几根才可知」，没有处理「投影本身被未来改写」——仍是未来筛选。

Codex 053 合成反例（`tests/test_wedge.py::codex053`，复制自其 review_probe.py）：

| 输入 | v1 causal | v1.1 causal_stream |
|---|---|---|
| 前 55 根 | first=9、last=50、known=53，第 54 根上破 | 同左 |
| 同样前 55 根 + 后 45 根 | **空**（H60 确认于 63，取代 H50） | **同一事件、同一轨道、仍是第 54 根上破** |

后果：v1 causal 的事件集合不是交易时当时能看到的集合；run2 的「causal 75% vs 安慰剂 71%」不能作实时口径证据。
v1 descriptive 本来就是事后最长段（含后视），本次不改它的定义与行为。

## 2. v1.1 causal_stream 定义（`wedge.stream`）

第 T 根收盘后，只用 `bars[:T+1]`、`atr[:T+1]`，按以下顺序处理：

1. **冻结中的事件**：用第 T 根收盘对**冻结轨道**判定：收盘 > 上轨 = 上破、< 下轨 = 下破；
   到 `min(⌊交点⌋, 认出根 + 1 + 120)` 仍未越线 = 未突破（no_break）。轨道不随之后的摆动点重画。
2. **推进投影**：把确认根 = T 的分形点（左右各 k 根，影线价）按 `alternating` 的同一规则推进交替投影：
   同类相邻时更极端的新点取代末端，等价或更不极端的丢弃；同根既高又低的点不进投影。取代只按当时已确认的点发生。
3. **找当时成立的楔形**：若没有冻结中的事件、且投影末端在第 T 根发生变化（新增或被取代），
   在**当时**投影里找以末端为终点、首点 idx > floor、跨度 ≤ 250 根的连续段，用 v1 相同的 `check` 判成立
   （两线向下收敛、上轨更陡、交点在段末之后、段内 K 线在两线 ± 0.3·ATR 内、触点 ≥5 且每侧 ≥2、段长 ≥15 根），
   取**首点最早**的成立段；认出根 = T。
   - (段末, min(⌊交点⌋, T)] 内已有收盘越线 → **认出前已破**（broke_before_known），单列，不等突破；
   - 认出时已过交点且期间未越线 → 未突破；
   - 否则冻结（轨道、摆动点身份 `pivots`、认出根），从 T+1 起等突破。
4. **不重叠**（与 v1 相同）：上/下破 → floor = 突破根；未突破 → floor = ⌊交点⌋；认出前已破 → floor = 认出根。

**事件只追加：** 每个事件的认出、定性各写一条日志 `(根, recognize|resolve, eid, …)`；定性只能写一次（改写即抛错）；
已发事件永不删除。数据结束仍未定性的事件 = 不完整（incomplete）。

与 v1 causal 的其它差别（都由「只用当时信息」推出，不是看结果后的选择）：
候选先按**时间**（哪一根先成立）再按首点早晚；v1 先按首点、再在最终投影里找最早成立的段末。

识别参数（k=3、容差 0.3·ATR、段长 15–250、等待 120、观察 120、回抽 30 天、失败 5%、安慰剂 50 条）、
突破/结果定义、安慰剂构造、敏感性变体（k=2；容差 0.5）、16 个标的与分组，全部与 v1 相同。

## 3. 前缀一致性（运行门槛）

对任意截断长度 cut：用前 cut 根（ATR 也只在前缀上算）跑出的日志 = 全数据日志里根 < cut 的部分；
认出根 < cut 的事件身份（首/末摆动点、认出根、两轨四点、触点数、交点、摆动点身份）一致；
定性根 < cut 的定性一致，否则在前缀里仍未定性。

- 合成测试：Codex 反例逐个 cut 全量核对；另含尾部扰动（12 条随机尾巴，含极端高低点）、重复极值（取整价格、等价高点不取代）、
  认出前同类取代（L44 取代 L40）、未成熟（H50 未确认前无事件）、认出未破（不完整）、认出前已破、到期未突破、
  随机游走（含重复价）在事件邻近根与等距根的截断。
- 设计集：运行脚本先对每个变体、每个标的在「每个事件的认出根、认出根+1、定性根、定性根+1」及每 250 根做前缀重放；
  **任何不一致即中止、不写结果目录**。报告公开核对截断点数与不一致数，并列出 v1 causal → v1.1 的事件变化计数
  （同一身份、结果相同、仅 v1、仅 v1.1、两者有方向数）。

## 4. 分母口径（v1 报告曾混用，Codex 053 纠正）

识别 = 认出前已破 + 不完整 + 未突破 + 有方向（上 + 下），四类分开报告。向上占比 = 上 / 有方向；
配对差只在「有方向且有安慰剂配对」的事件上算，配对 n 单列。不得再以识别总数当作方向检验的样本数
（例：run2 causal 是「387 次识别，其中 124 认出前已破、1 不完整，262 有方向」，不是「387 另 124」）。

## 5. 推断：待 D 包校准，不作结论

plug-in z（Σ(真实 − 安慰剂比例)/√Σp(1−p)）把少量安慰剂的样本比例当成已知概率：
Codex 053 合成零模型下，每事件 2 个控制时名义 5% 误拒 26.9%，50 个控制 5.6%；50 个控制减少这一误差，
但不证明在跨品种同日相关、相邻窗口与共享控制路径下有效。因此 v1.1：

- z / p 照算但移入机器字段 `inference_uncalibrated`（带 `status: 推断待 D 包校准，不作结论`），顶层不再输出 `pb_z` / `pb_p`；
- 报告表头与每格都标「推断待 D 包校准，不作结论」「未校准」；极小 p 显示为 `<1e-4（科学计数）`，不显示 0；
- 不据此 p 做 Bonferroni 或任何「显著」表述。正式推断由 D 包（事前固定估计对象、合成校准误拒率）另行定。

## 7. 已知局限（与结论同时呈现）

- 识别仍是规则化代理，不等于 Bulkowski 人工挑形态；原站 68% / 800 多笔是出处核对，不是本项目已复现原研究。
- 固定轨道几何的安慰剂已控制掉楔形信息的一部分：配对差不是楔形全部预测价值，安慰剂接近 68% 也不构成因果分解。
- 设计集的前缀核对只在抽定截断点做（事件邻近 + 每 250 根），合成测试才是逐根全量；抽查通过不等于每一根都核过。
- 「首点最早」的选段规则、未突破时 floor 取交点，都沿用 v1 的选择，未校准。
- 16 个标的中 7 只个股是今日存活的知名股票，有幸存者偏差；期货连续合约换月有机械跳空；个股未含分红。
