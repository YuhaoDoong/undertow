## 1. 要复现的说法（出处已核对：thepatternsite.com/fallwedge.html，统计更新于 2020-08-27）

下降楔形 800 多笔，向上突破 68%；牛市上破失败率（走不出 5%）26%、下破 29%；回抽 62% / 74%；达到目标 62% / 29%；
突破平均在到交点距离的 61–62%；判据：两条下行收敛线、≥5 个触点（一侧 3、一侧 2）、≥3 周。样本期、市场、取样方法页面未写（基本是美股个股）。

## 2. 识别规则（全部参数未校准；看结果后不改，改须写进研究决策日志）

- 摆动点：分形高低点，左右各 3 根，影线价（`price_structure.fractal_pivots` + `alternating`）。
- 候选：一段连续摆动点（≥5 个，高、低各 ≥2）。上轨 = 段内第一个与最后一个高点连线；下轨 = 第一个与最后一个低点连线。
- 成立条件：两线斜率都 < 0，上轨更陡；交点在段末之后；段长（首末摆动点相隔）≥15 根（3 周）、≤250 根；
  段内每根 K 线最高价 ≤ 上轨 + 0.3·ATR、最低价 ≥ 下轨 − 0.3·ATR（ATR = 段首前一根的 Wilder 14 日）；
  距线 ≤0.3·ATR 的摆动点算触点，合计 ≥5、每侧 ≥2。
- 突破：之后第一根**收盘**在上轨之上 = 向上、在下轨之下 = 向下（作者一：盘中刺破不算）；到交点或 120 根仍未越线 = 不计方向。
- 两种认法：
  - **descriptive（主复现）**：同一起点取能成立的最长一段，突破从段末下一根找——接近人事后看图画线，有后视；
  - **causal（可交易）**：同一起点最早成立的一段，最后一个摆动点确认（+3 根）后才算认出，突破从认出下一根找；认出前已越线的单列。
- 不重叠：一个楔形突破（或到交点）之后，下一个楔形的起点必须在其之后。

## 3. 指标与对照

- 向上突破占比 = 上 / (上 + 下)，Wilson 95% 区间。
- 突破后 120 根内：最大有利波动 <5% 的比例（失败率）；30 根内回到突破时的轨道价（回抽）；到达目标（上破 = 楔形内最高价；下破 = 突破收盘 − 楔形高度）。
- **安慰剂基线（关键）：** 两条线都向下收敛，价格只要横着走就会先碰上轨，所以 68% 里可能有一部分是几何机械效应。
  每个楔形保留同一对轨道与起点价，换成本品种其它日期（相隔 ≥250 根）的收盘路径（按 ATR% 比例缩放）各 50 条，看先越哪条线。
  配对差 = 真实是否向上(0/1) − 安慰剂向上占比；报告均值与符号检验。
- 分组：个股（7，最接近 Bulkowski 的样本）、ETF 与期货（9）。跨品种同日事件不独立，合并数只作描述。
- 敏感性（事先列明，只作描述）：分形 k = 2；容差 0.5·ATR。

## 4. 已知局限

- Bulkowski 很可能是人工看图挑形态，我们是规则化识别，两者选出来的不是同一批形态；结果不同不等于他错，结果相同也不等于形态有用。
- 他的「平均涨幅」按理想出场口径算，这里不复现涨幅，只复现方向、失败率、回抽、达标率。
- 期货连续合约换月有机械跳空；个股为拆股调整、未含分红；样本只到 2015 年。
