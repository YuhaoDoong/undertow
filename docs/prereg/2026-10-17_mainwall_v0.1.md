## 唯一主问题

在同一套「主墙最近侧」选择下，卖主墙行权（A）是否比卖同侧 1·ATR 定距行权（B）有更好的含费模拟报价收益。
主终点：一组含费美元 P/L 的 A−B，退出沿用 v5 `pre_expiry_exit_policy`（含只买回短腿的残腿上下界/未知）。
**解释限制**：这比较的是给定墙侧下的行权选择规则，不能单独证明墙的因果支撑，也不能证明近侧方向比远侧准。

## 入场窗（v5 open 窗，ET 10:00–10:20，时刻只由 `shadow.window_bounds` 给出）

1. 先取 Sdec = 长桥 `quote` 常规时段 last（freshest_kind 必须是「常规」），**写入即冻结**（entry_decision 只写一次）。
2. 按冻结墙选近侧：墙已被 Sdec 越过或恰在墙上 → 该侧不合格（不换更远一层）；两侧都合格取 |K−Sdec|/ATR 小者；相等弃权；只一侧合格取该侧。
3. 候选：近侧 A（卖精确墙 K、外侧同宽保护腿必须恰好挂牌，缺失不挪腿）、近侧 B（v5 `pick_b`，以 Sdec 为现价、1·ATR，记距离残差，A=B 保留并标记）；远侧 A/B 同法构造，只作次要描述。
4. 候选写入后才取盘口；派生时**只接受 Sdec 冻结之后开始的报价尝试**，取窗口内第一次合格报价，不择优。
5. 盘前没冻结成的品种，开盘窗补一行机会母表（premarket 状态 = 最后一次失败原因）。

## 结算与分母

- 价格/费用：v5 同一模型（卖腿 bid − 买腿 ask 保守入场、mid_give 0.25 只作描述、每组 $3.20）。不是保证成交，也不是实际费率。
- payoff-floor-v1（含费最大收益 ≥ 含费最大亏损 10%）：未校准偏好；不通过 = 模型不入场，政策结果 0，候选保留。A 被挡**不改选远侧**。
- 政策结果：确定弃权（无墙 / 已越墙 / 等距 / 无候选 / 收益门槛）= 0；缺价、未成熟、残腿实值处置未知 = 未知（不折 0）。
- 机会类别（每行一类，优先级自上而下）：盘前失败原因 → sdec_missing → no_wall / already_beyond / tie → missing_contract → quote_missing → payoff_reject → immature → exit_unknown → entered_model（只有 A）/ pairable（A、B 都有值）。
- 铁鹰（次要）：两侧 A 在同一次报价尝试入场、同到期才合成，费用 $6.40；缺一侧不补 0；不把两侧最大亏损相加当必亏。

## 057 补修（2026-10-17，开始前；策略参数未改）

Codex 057 复核后、首个前瞻日之前的工程修正。25% 价域、≥E 分子、1·ATR、收益门槛、选边规则都没有改；以下只改时序、分母与采集质量。

- **前瞻起点冻结**：`CONFIG["prospective_start"] = "2026-10-19"`（写进配置 hash）。机会母表从这一天起按预存日历 × 品种枚举，账里没有的格记 `not_generated`；起点之前不告警，起点不因首笔结果后移。
- **冻结时序**：`attempt_started_at → inputs_consumed_at → frozen_at` 分开记；`frozen_at`（写入前再读时钟）必须早于 T 09:30 ET，且所选序列、参与交叉核对的另一源、期权快照的可得时刻都已知且不晚于 `frozen_at`，否则只追加失败尝试（`late_completion` / `input_availability_unproven`）。离线回放（时钟与墙钟相差 > 120 秒）拒绝写前瞻账。
- **原文身份**：缓存文件只读一次，同一份字节算 sha256、取 fetched_at、解析序列；参与决定的原文存入 CAS。缺身份的源不算 fresh。
- **回看覆盖**：ATR14 用到的最近 15 个交易日（预存日历）必须全在且 HLC 有限为正，否则 incomplete、不冻结；语境（只记录）回看约 266 根，可核部分缺根 → 语境置空、`context_status=incomplete`，行照常冻结；日历不覆盖的更早部分标 `ok_partially_verified`。
- **Sdec**：取回的发出与返回时刻都必须在开盘窗内，跨窗末不冻结。
- **确定弃权 = 0**：无墙 / 已越墙 / 等距 / 无到期 → A = B = A−B = 0；缺输入、缺报价、未成熟、残腿未知 → None，另记 A/B/A−B 区间（[A下界−B上界, A上界−B下界]）。报告列分母、点值、有界、未知各多少。
- **失败尝试账**：严格解析，坏行 → 原件不动、另存隔离副本、显式报 `premarket_attempts_corrupt`；追加 fsync 后回读核对。
- **盘中采样**：标的与各合约分开取、分开记；每次唤醒只补本桶尚缺的成员，每次尝试原样追加；无适用期权腿照样记标的与到墙距离；成员不齐 → partial（rc=1）。本桶末 6 分钟仍未补齐 → 通知 + `data/reports/FAILURE_<日>.txt` 兜底（只写状态）。
- **铁鹰**：两侧首个合格报价不同批 / 缺一侧 / 到期不同 → pnl=None 并记原因；同批时的结果标「原始报价情景，未套组合门槛，不是政策入场」。
- **daily**：研究阶段放进 `set +e` 区单独捕获返回码，失败照记阶段状态并告警，不再中断后续必需阶段。
