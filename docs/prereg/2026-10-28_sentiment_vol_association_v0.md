## 1. 唯一的问题

四个品种各自主波动指数处在**自身历史高分位**时，之后 1 日、5 日的**局部去趋势收益**，是否与同 regime 下
**中性分位**的日子不同？双侧，不预设延续或反转。

| 品种 | 主波动指数 | 收益标的 |
|---|---|---|
| gold | GVZ | GLD |
| silver | VXSLV | SLV |
| wti | OVX | USO |
| qqq | VXN | QQQ |

VIX 只是共享美股背景，**不**作为纳指的第二个主终点。

## 2. 定义（全部冻结）

**信号日 d 与可得时刻。** 指数数据日 d 的收盘值视为 d 收盘后发布、在下一交易日 d+1 开盘前可得（发布时刻未逐日核实，
记为假设）。**入场 = d+1 开盘**，不能用 d 当日已结束的收益。

**分位。** `sentiment.prior_midrank`：只用 d 之前最近 252 个有效观察（排除 d 本身），
并列取中位秩 `(#< + 0.5·#=)/n_prior`；n_prior < 252 的信号日剔除（不用不满窗口的分位）。

**分组。** 高分位组 `p ≥ 0.8`；中性组 `0.4 ≤ p ≤ 0.6`；其余不参与。**这是未校准的研究定义，不扫 70/80/90。**

**regime。** d 收盘价相对 d 及之前 200 个交易日收盘均线：收盘 > SMA200 为「牛」，否则「熊」（沿用
`stretch_backtest` 的 REGIME_N=200 定义，只用 d 及之前数据）。

**收益与局部漂移。** 价格用 Yahoo 日线**未复权** OHLC（GLD/SLV/USO 无分红；QQQ 季度除息约 0.1–0.2% 未调整，
是已知局限）。

- h 日原始收益 = `close(d+h) / open(d+1) − 1`，其中 d+h 是从入场 session 起第 h 个交易日（h=1 即 d+1 收盘）。
- 局部漂移 = `(close(d)/close(d−60) − 1)/60`（沿用 `stretch_backtest.DRIFT_N=60`，只用 d 及之前）。
- 去趋势收益（pp）= `100·原始收益 − 100·漂移·h`。
- 终点缺数据 → 该样本剔除，不顺延到另一天。

**样本期。** 各品种从「指数首日 + 252 个观察」与「ETF 有 260 日以上价格」中较晚者起，到 2026-10-27 之前
仍有完整 h 日终点的最后一个信号日止。

**VXSLV 版本边界（066 审查 P1）。** Cboe CSV 在 2022-02-11 → 2025-05-15 无数据；2025-05-15 ～ 2025-06-13 共 21 个
点为 2025-06-16 重启时的回算值（reconstructed）。规则：信号值或其 252 观察窗口**含回算点、或跨越 >10 日历日的
空档**的信号日一律剔除。

## 3. 抽样栅格（先定栅格，再分组）

- h=1：全部合格信号日。
- h=5：在每个品种的合格信号日序列上，从第一个合格日起按位置 `k % 5 == 0` 取不重叠子样本（相位 0）。
  先按这个栅格抽样，再分高/中性组；**不在两组内各自抽样**。
- 其它四个相位只作预先声明的敏感性描述，不挑最好的相位。

## 4. 检验家族与判定

- 家族 = 4 品种 × {1, 5} 日 × {牛, 熊} = **16 个双侧主检验**，Bonferroni α = 0.05/16 = **0.003125**。
  不能只把显著的格子留在分母里；样本不足的格子仍算在 16 项内。
- 每格：高组均值 − 中性组均值（pp），Welch t，Welch–Satterthwaite 自由度，**双侧 p 由 t 分布精确计算**
  （标准库实现正则化不完全 Beta，配单测；未实现之前只报统计量，不下显著性结论）。同时报两组 n、差、标准误、
  95% 区间与 Bonferroni 校正后的区间。边缘与 t 来自同一批不重叠样本。
- **样本门槛**：任一组有效 n < 50 → 只描述，不判定。
- **依赖诊断**（必须报告）：两组去趋势收益的 1 阶自相关；按 20 个交易日分块的移动块 bootstrap（2000 次，
  固定种子 20261028）给差值的区间，作敏感性描述。
- **判定措辞**：
  - p < 0.003125、两组 n ≥ 50、块 bootstrap 区间不含 0 且符号一致 → 「预注册回顾检验下检出关联」；
  - 显著但块 bootstrap 不稳 → 「初步关联，对依赖敏感」；
  - 其余 → 「未检出」。
  - 任何一种都**不是**「已验证预测力」，也不自动解读为延续或反转（要检验反转，须另冻结被反转的价格方向与期限）。
