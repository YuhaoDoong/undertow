# 术语表（固定名称）

用户 2026-10-16：「增仓层……和极强看涨信号、资金流向这种是一个东西吗？名称应该固定统一。」
以下是对用户说话、写研报、写代码注释时统一使用的名称。旧叫法只用于检索历史记录，新文字不再使用。

## 💰 增仓家族（同一份数据：前后两天期权链的 ΔOI + 用 IV 方向推断谁是主动方）

> 买方 / 卖方标签是**推断**（按 IV 涨跌与成交估计谁在主动建仓），不是观测到的真实主动方；下表所有「买 put / 卖 call」都按此理解。

| 固定名称 | 是什么 | 旧叫法（停用） | 证据状态 |
|---|---|---|---|
| **增仓方向** | 一个品种当天整体偏多 / 偏空 / 中性：全部行权价的加权增仓按买卖方归到看涨侧或看跌侧后比大小（看跌侧 = 买 put + 卖 call，看涨侧 = 买 call + 卖 put） | 增仓层、增仓层方向、资金流方向、加权增仓、call_direction | 金银 T2 探索：单品种时序命中黄金 72%（n=32）、白银 71%（n=28）——**2026-08-29 研究时点的固定样本**（AGENTS.md「单品种时序 vs 跨品种合并」表），不是现行样本量；比探索观察强、够不上已验证（Bonferroni 后不过，n < 50，只覆盖两个月）。原油（53%，n=30）、QQQ（58%，n=12）**未建立有效性证据**（不显著，也不等于证明无效）。只展示，不改结论 |
| **增仓强信号**（⚡强 / ⚡极强） | 增仓方向一边倒到过阈值：顺向压力 ≥ 3× 逆向、主翼（Δ 0.18–0.45）一边倒、净建仓 ≥ 3,000 张；**极强 = 波动率面同向追认** | 强信号、极强看涨 / 极强看跌、⚡信号 | 与增仓方向同源，方向 100% 共线——是同一个读数的加强版，**不是额外一票**。signal_ledger 在 2026-10-16 读数时 n=16、命中 56%，不显著（样本随台账增长，现行数字以 `undertow signals` 为准）；**「越强越准」没有证据支持**（当时极强看涨 n=4、次日 25%，n 太小，既不能证明更准也不能证明更差） |
| **逐行权买卖方** | 把同一推断按行权价 / 到期拆开：哪个价位是卖方压制、买方保护、买方了结等；到期阶梯里的「当日范围买卖方净倾向」是它在单个到期上的合计 | 资金动向、资金流向、买卖方净倾向、卖方压制 / 买方保护（作为结论时） | 用于选腿和看谁在哪个价位建仓；本身不单独给方向结论 |

三者是**同一份数据的三种粒度**，任何时候都不能当成互相印证的多份证据。

## 其它常用名称

| 固定名称 | 是什么 | 不要混用 |
|---|---|---|
| **墙位**（🧱 结构） | 前一交易日结算的 OI **存量**最集中的行权价（call 墙 / put 墙），按到期拆分；查墙一律 `undertow walls` / `expiry` | 不是增仓（增仓看昨天一天的变化，墙看累积存量）；与增仓来自同一份快照，信息部分重叠 |
| **偏斜防守读法** | 外部作者一的期权结构读法（偏斜水平与翻转） | 不叫「期权结构」，避免与墙位、增仓混用 |
| **超买 / 超卖**（📈 价格） | 偏离度 + 回撤度合并分位（`undertow tech`），整条链上唯一不碰期权的一层 | 超卖不是看涨信号：当前白银「偏超卖」档 5 日边缘 +0.31pp、t=1.12，不显著 |
