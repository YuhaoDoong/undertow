## 分析品种为什么值得单独跑（不交易也有价值）

`tlt` / `spy` / `dxy` / `wti` 不参与交易，但它们的**持仓层与偏斜层带来交易品种没有的信息**：

- **TLT（美债）**：利率是金银的核心驱动。实测「TLT 涨幅前 10% 的日子里，黄金 66% 跟涨、
  当日均值 +0.396%（全样本 +0.043%，9 倍）」——美债的挤空信号会先于金银出现。
  ⚠️ 其 COT 用 `ULTRA UST BOND`（超长债期货），久期最接近 TLT 但**不是同一标的**
  （TLT 是现券组合、期货是特定交割篮子），持仓结构可参考、不可等同。
- **SPY（标普）**：与 QQQ 日收益相关 **0.95**（价格冗余），但**持仓层完全独立**——
  实测投机资金在标普长期净空（均值 −4.2%、160 周仅 18 周为正）、纳指长期净多
  （+5.1%、131 周为正），**周变化相关仅 −0.07**。
  只看 QQQ 会漏掉大户在标普端的极端持仓。SPY 还是全球最深的期权链，其 put-call
  偏斜是**市场整体对冲需求**的基准表。

- **IWM（罗素2000·观察）**：与 SPY 相关 0.89、QQQ 0.82，**信息大半冗余**，不作独立分析源。
  但它性格鲜明：TLT 大涨日（避险买国债）IWM 当日均值 **−0.969%，是全样本的 −25 倍**，
  比 SPY(−19×)、QQQ(−11×) 都敏感——**小盘是三者中对衰退最敏感的那个**。
  IWM/QQQ 比值现处 20 年 **6% 分位**（小盘相对大盘科技的极度弱势区）；
  这是周期还是结构变化，**本模型（日频到周频）回答不了，不要假装能判断**。

**判断一个品种要不要加，看的不是价格相关性，是它的持仓/结构层是否独立。**
例外是 `iwm` 这类「为将来攒数据」的观察品种——理由是链不可再生，不是信息独立。

## 数据源与诚实边界（务必如实转达用户）
- **持仓 COT**：CFTC 官方（免费）。物理商品走 Disaggregated，金融期货（美元指数）走 Legacy。✅ 真实，周频、滞后约 3 天。
- **期权链**：CBOE 延迟报价，**用 ETF 代理**（GLD≈金 好 / SLV≈银 好 / USO≈油 **弱**）。黄金可信，原油位点仅定性。**这不是机构用的真·CME 期货期权**——后者需券商/付费数据源（如 IBKR）才能拿到。
- **价格/位点**：最终位点用**真实期货价**（Yahoo GC=F/SI=F/CL=F/DX=F）+ 当日实时比值换算，免乘数漂移。
- **宏观**：FRED（真实利率/美元/通胀预期）。**波动率**：CBOE GVZ/OVX/VXSLV。
- 美元指数（dxy）暂无合适免费期权代理，只走持仓+价格+宏观，用 `analyze dxy`（不出 HTML 报告）。
- **事件日历**：远期锚点（FOMC 全年/COT/OPEX）手维护于 `config/calendar.json`（日期须核官方源）；本周的数据预测/前值/影响自动拉 **FairEconomy 公开 JSON feed**（ForexFactory 数据方，合法消费公开 feed、非爬网页，标注 (FF)）。**不爬 ForexFactory/Investing 网页**（Cloudflare 反爬 + ToS）。
- 全部只作**波段级风险情境**预警，不构成交易指令；不绕过任何数据源的反爬/ToS。

## 日常习惯（重要）
**CBOE 不提供期权历史**——资金流的日对日 diff 只能靠自己每天攒。每个**美东交易日**跑一次：
```
python -m undertow snapshot      # 落盘当日全品种期权链；休市重复数据会自动跳过
```
快照 gzip 后纳入 git，push 即等于备份这份不可再生的历史。

## 解读要点
- `report` 的 HTML 自带表格/图/情景，直接把结论（bias + 可信度 + 关键位）讲给用户，并带上**机构口径的买卖方表**与**价差结构**警示。
- 始终区分：**真实数据**（COT/真期货价/宏观）vs **代理近似**（ETF 期权位点）。原油务必声明 USO 代理弱。
- **判读方法论**：逐行权价「买方 vs 卖方」（OI 增减 × Delta 修正后相对 IV 方向 + 绝对 IV 闸门）、
  垂直价差结构识别、波动率面「买方确认」检查、综合层「近端 vs 中期」双周期分层——
  均已实现在 `undertow/analyze/` 各模块，并与每日报告方向结论逐条留痕、持续自校。

## 交易哲学（机构口径，已落成工具里的纪律，务必转达给用户）
把方向研判翻译成**能不能下手**时，遵循以下几条——它们不是口号，已固化在 `fib` / `risk_reward` /
`strategy` 模块里，用确定性数字执行：

1. **先看盈亏比，再谈方向。** 方向对≠这单值得做。任何一单先算 R:R =｜目标−入场｜/｜入场−止损｜：
   **< 1:1 直接不做**；2:1 才配得上一次进场（对应约 40% 胜率的盈亏平衡）。`fib` 输出把「差/中/优」
   评级直接标在每个情景上。
2. **别追高，等回调。** 顺势不等于现价追。工具对每个方向同时算「现价追」与「等斐波回调（默认 0.5）」
   两情景的盈亏比——通常追高 R:R 掉进「差」，回调进场才进「中/优」。让用户**看着数字**决定等哪个价。
3. **入场锚在斐波，止损锚在结构。** 加仓/短线入场区取当前摆动腿的 0.382/0.5/0.618 黄金回撤；
   止损放**起涨点（1.0）或 0.618 下方**——腿一旦被跌破即「腿失效」，纪律止损，不硬扛。
4. **长短线资金分离。** 波段底仓与短线仓分开记、分开管：短线打不中不动底仓，底仓的方向判断不因
   短线止损而动摇。（工具在 `report` 情景里区分触发/失效/目标，正是给这两类仓不同的执行口径。）
5. **别用结果倒推决策。** 一单赚赔是概率兑现，不改变「进场时盈亏比够不够」这个唯一标准。回测
   （`backtest`）校准的是**长期期望**，不是为某一单事后找理由。

> 这些都是**波段级风险纪律的量化呈现**，不是投资建议、更不构成交易指令；工具只给「盈亏比够不够、
> 该等哪个价」的确定性参考，是否下单由用户自行决定。

## 当日决策研判（混合模式：确定性打底 + 交互润色）
报告顶部的「🧭 当日决策研判」把上面所有层**规则化合成**成交易者真正要的四问，模块 `analyze/verdict.py`：
1. **做空？** —— 有无近端看跌信号/近中共识；趋势没坏时明确「不是做空位置（防守≠看空、逆势负 edge）」。
2. **现价能不能追？** —— 读斐波盈亏比闸门：追势 R:R 差就「别追、等回调到关键区」；逆势微腿（上升趋势里的
   回调/下降趋势里的反抽）识别为「回调买/反抽卖、不追」，不会把回调误说成做空。
3. **短线仓** —— 腿顶+追势 R:R 差+进攻结构散 → 获利了结/收紧；强信号在 → 跟势；逆势微腿 → 等回调/反抽。
4. **长线仓** —— 跟中期 bias：偏多按年度拿、偏空逢反弹减（长短线资金分离）。

**关键设计**：这套研判**全程确定性、无 LLM、数字全来自上游模块**——因此能跑在**每日无人值守定时任务**里
（`scripts/daily_update.sh`，出强信号还弹 macOS 通知 + 落 `ALERT_<date>.txt`），结论也进 index 每品种一行。

**混合模式**：定时任务/index 用这套确定性结论打底；**当用户在交互式会话里让你（LLM 助手）分析时，你应先读
报告/`verdict` 的结构化结论与数字，再在其上叠一段像样的流畅叙述**（拆短线/长线、点名关键位、带盈亏比数字），
但**方向结论与所有数字以 `verdict`/上游模块为准，你不得自行改判或臆算**——这正是"LLM 不碰算术"的落地。
