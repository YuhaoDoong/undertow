## 这一层的规矩

**默认不进研报、不进方向投票。** 先建好、能取数、有测试锁住口径，用得上时再单独接线。
任何子模块要进研报，得先过统计检验（`analyze/validation.py`）——

## 周期分工（用户定义，硬约束）

| 周期 | 角色 | 用途 |
|---|---|---|
| 15m | entry | **只看开仓平仓的入场出场时机** |
| 1h | direction | 方向与波段/趋势 |
| 4h | direction | 方向与波段/趋势（用户主看） |
| 1d | direction | 方向与波段/趋势 |

**15m 的读数不得用于判断方向。** 15m 上的 MACD 金叉在日线级别可能只是噪声里
的一次抽动，拿它当方向信号等于把噪声当趋势。`read_multi()` 默认周期是
`("1h","4h","1d")`，要看 15m 必须显式传入。

## 已建子模块

### frames —— 多周期数据层

长桥 K 线周期里**没有 4h**，由 1h 按交易日分组聚合。
不能对全序列每 4 根盲分：美股 RTH 每日 7 根 1h，不是 4 的整数倍，
盲分会把前一日尾盘和次日开盘拼成一根、横跨隔夜跳空
（2026-08-27 实测 RSI6 一度算出 100）。

取不到数据抛 `KlineUnavailable`，**不返回空列表** —— 否则"没数据"会被
静默当成"没信号"。

实测四个周期都到位（2026-09-03 盘前，末根均为 9/2）：

```
 15m  200 根  2026-08-24 → 2026-09-02   [择时]
  1h  250 根  2026-07-15 → 2026-09-02   [方向]
  4h  200 根  2026-04-13 → 2026-09-02   [方向]
  1d  300 根  2025-06-25 → 2026-09-02   [方向]
```

### macd —— CM_Ult_MacD_MTF 口径

用户提供的是 ChrisMoody 2014-04-10 的脚本。移植时有**一处必须注意的口径差异**：

```pine
signal = sma(macd, signalLength)    // ← SMA，不是 EMA
```

TradingView 内置 MACD 和绝大多数教科书用的是 `EMA(macd, 9)`。
两者在拐点附近能差出一整根的方向 —— 实测 GLD 4h 柱状图
SMA 口径 −3.896 vs EMA 口径 −3.308，差 18%。

既然用户照着这个脚本看盘，本模块**默认跟它一致**（`signal_ma="sma"`），
保留 `"ema"` 选项对照。口径不一致就是对不上盘 ——
2026-08-27 技术面滞后两天那次，根子就是我们和用户 App 不同源。

另一处易错点：Pine 的 `ta.ema` 种子是 **SMA(n)** 而非首值。
用首值当种子会让前几十根偏离，早期柱状图对不上 TradingView。

**四色柱**是这个脚本比裸看金叉多出来的信息：

| 颜色 | 条件 | 含义 |
|---|---|---|
| aqua | hist>0 且走强 | 多头强化 |
| blue | hist>0 但走弱 | 多头衰减（顶部预警） |
| red | hist≤0 且走弱 | 空头强化 |
| maroon | hist≤0 但走强 | 空头衰减（底部修复） |

颜色翻转**早于零轴穿越，也早于金叉死叉**。blue 出现时价格常还在涨，
但动能已在减速。注意脚本里 `hist <= 0` 进 histB 分支，**0 归零下侧**。

### supertrend / ut_bot —— 两个 ATR 追踪止损（用户 2026-09-03 问「有什么区别」）

**同一族**：都是「ATR 追踪止损 + 状态机」。差异在轨道结构和敏感度。

| | Supertrend | UT Bot |
|---|---|---|
| 源 | `hl2`（含影线） | `close` |
| ATR 倍数 | **3.0** | **1.0** |
| 轨道 | 上下**两条**棘轮轨，trend 决定显示哪条 | **一条**追踪止损线，自己在价格两侧翻转 |
| 翻转比较对象 | close vs **前一根**的对侧轨（`up1`/`dn1`） | src vs **前一根**的 stop |
| ATR 口径 | 可切 RMA / SMA(tr)，默认 RMA | 固定 RMA |
| 可选源 | — | Heikin Ashi（默认关） |

移植时最容易写错的一处：Supertrend 的翻转判定用的是 `up1`/`dn1`（**前一根**的轨），
不是当根值。写错了信号提前一根 —— 4h 上就是提前 4 小时，回测会凭空多出一截收益。

UT Bot 源码里两处值得知道：
1. `ema = ema(src, 1)` —— 周期 1 的 EMA 就是 src 本身（alpha=1）。绕这圈只为用 `crossover()`。
2. `buy = src > stop and above`，而 `above = crossover(src, stop)` 已蕴含 `src > stop`，
   **前半个条件是冗余的**，`buy ≡ above`。

#### SuperTrend STRATEGY 版（用户 2026-09-03 问「这个策略是一样的吧」）

**计算部分逐字符相同。** 从 `atr2 = sma(tr, Periods)` 到
`sellSignal = trend == -1 and trend[1] == 1`，两份是同一段代码，
同一作者（KivancOzbilgic）把 indicator 包成了 strategy。实测在 SLV 4h 上
两者的 buySignal/sellSignal 下标完全一致，我们的 `supertrend.py` 已覆盖，
**不需要新模块**。

差的是包装，而包装带来五处实盘差别：

1. **always-in-market**。`strategy.entry` 在反向信号时自动平仓反手，
   **没有空仓状态**。永远满仓，只在多空之间切。
2. **无止损、无止盈、无仓位管理**。每次翻转全仓反手。
3. **默认 0 手续费 0 滑点**。脚本的 `strategy()` 没写
   `commission_type` / `slippage`，TradingView 策略测试器就按 0 算。
   在那上面看到的净利润曲线，是把成本假设全关掉的样子。
4. **成交在次根开盘，不是信号根收盘**。信号在收盘确认，
   `strategy.entry` 默认下一根开盘成交。
5. **可调日期窗口**（`FromYear`…`ToYear`）是过拟合的经典温床 ——
   挑一段好看的时间，曲线就好看。

第 4 条不是细节，它直接改结论：

| | 信号根收盘 | 次根开盘 | 差额 |
|---|---|---|---|
| SLV 1d ST | +83.7 | +69.0 | **−14.6** |
| GLD 1h ST | +4.8 | +0.3 | −4.5 |
| GLD 1d ST | −10.3 | −14.3 | −3.9 |

六个组合里五个变差。趋势跟踪的信号出在极值附近，次根开盘往往已经跳空过去，
这一截滑点是它的天然成本。

因此建了 `ta/backtest.py`，把三条假设焊死不留可选项：
次根开盘成交、必计换手成本、always-in-market。

三条读得出来的东西：

1. **样本小到换个成交假设就翻盘**（12 个里翻了 3 个）。这本身就是结论：
   7~42 段撑不起任何"某某指标有效"的说法。
2. **跑赢的四个里三个在标的下跌段**（GLD 4h −7.5%、SLV 4h −13.5%）——
   趋势跟踪的价值在于**能做空**，单边上涨里必然跑输，翻转必然发生在回调处。
3. **胜率评价这类指标是错的**。它们天生低胜率（30~44%）靠厚尾大赢单，

4. **UT Bot 的高频是纯损耗**。SLV 1d 上它 42 段、成本 4.2%，
   Supertrend 8 段、成本 0.8%。同一段行情，切得越碎丢得越多。

⚠️ 样本 7~42 段，**不足以支持任何结论**。上表是描述性统计，不是回测结论。
统计口径由 `ta/backtest.py` 固化，改不了成交假设。

#### 它们可能真正有用的地方

不是拿来判方向，而是**当离场线用**。Supertrend 的轨本来就是移动止损：
多头时下轨在价格下方 N%，跌破即离场。这和用户给 15m 的定位
（「只是看开仓平仓的入场出场时机」）是同一件事 —— 只不过 Supertrend
把它放在了 1h/4h 上。

要接进来的话，合理的用法是：**已有仓位时给一条离场线**，而不是给一个开仓方向。
这需要单独检验，现在没做。

### stoch / risk —— 取自 "EMA Trend + MTF Stochastic Strategy"（用户 2026-09-03）

这份跟前面几个不是一类：**它是完整交易系统，不是单指标**。
而且明显更成熟——写了手续费（`commission_value=0.02`）、有分阶段止损、
时间止损、风险仓位。前面那些 strategy 版全是 0 成本假设。

结构是四层：EMA(38/62) 定趋势 → MTF 随机指标择时 → 分阶段 ATR 止损出场
→ 风险仓位定手数。

#### 没有整体移植的三个理由

**1. 14 个可调参数。**
`emaFast(38)` `emaSlow(62)` `len(11)` `smoothK(3)` `smoothD(3)` `upLine(80)`
`lowLine(20)` `atrLen(14)` `atrStopMult(1.5)` `breakEvenR(1.0)` `trailStartR(1.5)`
`trailATRMult(1.5)` `maxBarsInTrade(60)` `riskPercent(1.0)`。

**38 和 62 这种数字几乎肯定是网格搜索出来的**——没有人会凭直觉选 38。
移植它等于把别人在别的品种别的周期上的过拟合搬进来。

**2. 确认仪表盘是重复计数。**

```pine
bullScore = (trendUp ? 40 : 0) + (k > d ? 20 : 0) + (mtfK > mtfD ? 20 : 0) + (k > 50 ? 20 : 0)
```

100 分里有 **60 分来自同一个随机指标的三个侧面**（k>d、mtfK>mtfD、k>50）。
这跟我们在 SMC vs 期权墙上发现的问题是同一个：同源信号相互印证是假象，
它只是把一个信号数了三遍。权重 40/20/20/20 也没有依据。

**3. 一处实质 bug。**

```pine
entryPrice := close
strategy.entry("Long", strategy.long, qty=qty)
```

`entryPrice` 记的是**信号根收盘**，而 `strategy.entry` 在**次根开盘**成交。
后面 `currentR = (close - entryPrice) / entryStopDist` 的基准，
是一个从未成交过的价格。次根跳空高开时实际成本更高，而 R 用更低的
`entryPrice` 算 → 过早判定盈利 1R → 把止损"移到保本"，
而那个位置对实际成本来说是亏的。跳空越大错得越多。

我们的 `risk.Position` 强制传入实际成交价，不接受信号价。

#### 移植了什么

**`stoch.py`** —— 随机指标本身是标准指标，值得有。
MTF 分支照实现，包括 `lookahead_off` 的对齐语义（低周期只能看到已收盘的
高周期 K 线）。有一处要知道：`ta.linreg` 是拟合不是均值，**可以外推出
[0,100] 之外** —— 实测 GLD 1h 的 MTF-k 到了 −6.9。
所以脚本的 `crossover(mtfK, 50)` 作用在一个无界量上。

**`risk.py`** —— 这是那个脚本里**唯一值得单独拿出来的东西**：
与具体指标无关的通用风控结构。入场信号可以换（Supertrend、UT Bot、
我们自己的墙位），这套出场逻辑照用。

三段式止损：初始 1.5×ATR → 浮盈 1R 移保本 → 浮盈 1.5R 开始 1.5×ATR 追踪，
只收紧不放松。止损触发用最高/最低价判定，不是收盘 ——
收盘判定会漏掉盘中被扫，回测显著虚高。

风险仓位：`手数 = 权益 × 风险% ÷ 止损距离`。每笔亏损固定为权益的 1%，
止损远则手数少。比固定手数或固定比例仓位都正确，
后两者在波动大时敞口自动放大。

#### 实测：同一组入场，只换出场结构

用 Supertrend 的翻转作入场（控制变量），四种出场：

| | 无止损 | 固定1.5ATR | 纯追踪 | 三段式 |
|---|---|---|---|---|
| GLD 1h（持有 +8.8） | +3.9 | +2.6 | −1.5 | +1.4 |
| GLD 4h（持有 −7.5） | −1.2 | −3.8 | −3.4 | −6.7 |
| GLD 1d（持有 +31.1） | −15.6 | +5.3 | +13.1 | **+16.5** |
| SLV 1h（持有 +14.6） | +4.7 | +6.1 | +5.7 | +3.5 |
| SLV 4h（持有 −13.5） | +23.0 | +12.7 | **+30.5** | +29.0 |
| SLV 1d（持有 +78.9） | **+69.9** | −5.8 | −2.3 | −4.5 |
| **合计** | **+84.7** | +17.1 | +42.1 | +39.2 |
| **去掉 SLV 1d** | +14.8 | +22.9 | **+44.4** | +43.7 |

**最优方案取决于要不要那一行。** 带上 SLV 1d，无止损碾压（+84.7）；
去掉它，无止损变成最差（+14.8），纯追踪和三段式反超到 +44。

原因不难理解：SLV 那段白银涨了 78.9%，无止损的趋势跟踪能吃到大部分；
一加止损就被反复扫出去，错过大波段。**止损保护了小亏，也切断了大赢**,
而趋势跟踪的收益全靠少数大赢单。

**结论：这个测试无法证明三段式止损更好。** 6 个组合、每组 6~13 段，
任何单个组合都能主导全局。这跟上一节的教训是同一件事——
样本小到换个假设、去掉一行就翻盘。

真要用它，正确的问法不是"哪种止损更好"，而是"**我这笔仓位能承受多大回撤**"。
风险仓位那部分（每笔固定 1% 风险）不需要统计检验就成立，它是账户管理不是预测。
