## 第一步：确定卖哪道墙　✅ 已定版

## 第 2.1 步：持有到期时，到期日 × 价差宽度的收益结构　✅ 已测

脚本：`scripts/step2_spread.py`。卖腿固定用第一步的墙，买腿往外 N 档，
**全部持有到期，不考虑提前平仓**。

### 「N 档」是多少美元
SLV 行权价在 50~62 主要是 **$0.50 一档**（部分区段 $1.00）：
```
1 档 = $0.50   2 档 = $1.00   3 档 = $1.50   5 档 = $2.50   （中位数）
```
**宽 3 档 = $1.50 价差，不是 $3.00。**

### 破墙率（DTE 步长 1，全测）
```
put  DTE 1~45 共 307 笔　破 0 = 0.0%
call DTE 1~45 共 263 笔　破 74 = 28.1%

call 逐 DTE：1~5 平台 7.1%；6~7 跳到 16%；8+ 到 25~50%；42~44 达 100%
```
put 侧全 0 是样本期上涨送的，无信息量。**call 侧是唯一的逆势证据**，
把它当作"方向不利时会怎样"的代理。

### 三条曲线方向不同（这是核心）
```
日均权利金(theta)   DTE 1 最高 $4.51/天，单调降到 DTE 39 的 $1.39
手续费占权利金      DTE 1 吃掉 71%，DTE 14 只剩 10%
call 破墙率        DTE 1~5 平 7.1%，DTE 8 起跳到 30%+
```

### 扣手续费后的净日均收入（宽 3 档）
```
DTE  2   净日均 $2.14   净收入  $4.3   占用 $143   call破墙  7%   ← 最优
DTE 14   净日均 $2.07   净收入 $29.0   占用 $205   call破墙 45%
DTE 13   净日均 $2.06   净收入 $26.8   占用 $207   call破墙 44%
DTE  9   净日均 $1.85   净收入 $16.6   占用 $130   call破墙 33%
DTE  4   净日均 $1.79   净收入  $7.2   占用 $140   call破墙  8%
```

**结论：短 DTE 是双赢，不是权衡。**DTE 2 与 DTE 14 净日均几乎相同
（$2.14 vs $2.07），破墙率却差六倍。两个机制同向：theta 临近到期最快、
暴露时间最短。这与"卖长期权收得多"的直觉相反 —— 长期权绝对权利金高
（DTE 39 收 $54 vs DTE 2 收 $7.5），但摊到每天只有 $1.31 还要担 50% 破墙率。

**宽度：2~3 档最优。**宽 1 档被手续费拖垮（DTE 1 手续费占 93%），
宽 5 档占用翻倍而权利金不成比例增加。

**现实约束**：DTE 2 净收入仅 $4.3/笔而占用 $143 —— 账户 $299 时开一笔用掉
一半资金只赚 4 块 3。DTE 4 净日均 $1.79（DTE 2 的 84%）、净收入 $7.2、
破墙率同为 8%，绝对金额更实用。

## 第三步：出场规则　✅ 已测

脚本：`scripts/step3_exit.py`。开仓完全沿用第一/二步口径，只换出场逻辑。
逐日推进：每个可交易日从当天快照取卖腿/买腿真实报价算平仓成本
（买回卖腿吃 ask 方向、卖出买腿吃 bid 方向，中价让 25%），
**提前平仓计两次手续费**（$3.20 × 2）。

### 两侧对照（SLV，墙上，宽 3 档，DTE 7）
```
规则              call(逆势)   put(顺势)   两侧合计
持有到期            -329        +249        -80
破卖腿即平           -80        +249       +169   ← 唯一两侧都不吃亏
换墙即平            -302        +113       -189
浮盈50%平           -134        +116        -18
破墙或浮盈50%        -21        +116        +95
```

**结论：只在「收盘越过卖腿」时平仓，其余一律持有到期。**
- 逆势时把亏损砍掉 76%（−329 → −80）
- 顺势时**一次都不触发**（put 侧 0 破墙），收益分毫不减

**换墙即平是坏规则**：两侧都差，还把最差单笔从 −$2 恶化到 −$45，
平掉 27~75% 的仓位却几乎不减亏（call 侧 −329 → −302）。
用户 2026-09-01 的判断「换墙是新开仓的换墙，不是让你浮亏平仓」得到证实。

**「破墙且换墙」与「破卖腿即平」结果完全相同** —— 破墙时几乎总是伴随换墙，
多加这个条件不改变任何事，不必引入。

## 三步法的完整规则（截至 2026-09-02）

```
① 选墙  gamma.pick_sell_wall()
        最大墙=最近墙 → 卖最大墙
        最大墙≠最近墙 → 朝现价挪一层；挪过去缓冲<3% 则退回最大墙
        最大墙自己也<3% → 弃权
② 建仓  DTE 2~4，宽 2~3 档，卖在墙上或墙内 1 档
        （墙内 1 档破卖腿率与墙上相同，权利金多 24%）
③ 出场  只在【收盘越过卖腿】时平仓；换墙不平、浮盈不平
```

⚠️ **这套规则仍未通过生死线**：第 2.1 步算出的平衡破墙率是 2.9%~4.8%
（DTE 2~4、宽 2~3 档），而 call 侧实测持有到期破墙率 7%~8%。
第三步的破墙平仓把亏损砍掉 76%，是把实际结果拉回平衡线附近的关键，
但两侧合计 +169 这个数仍然全部来自 put 侧的顺风。
