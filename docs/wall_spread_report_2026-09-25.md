> 项目：undertow（纯标准库 Python，期权持仓情报工具，服务一个真实小额账户）。
> 本报告汇总「墙位卖方价差」从立项到今天的全部思路、方法、数据与结论，供独立审查。
> 所有数字均可用仓库脚本重跑；每一节标注了脚本与落盘产物。

## 0. 一句话结论

这套策略一开始叫「卖墙价差」：找到期权 OI 堆积的行权价（墙），卖离墙的信用价差，赌墙撑住。
八步检验下来：**墙的位置不提供支撑；策略真正的边是短到期波动率溢价（VRP）；
方向该由持仓变化（增仓层）决定；行权价距离该用 ATR 倍数定；亏损尾巴集中在 ATR 扩张日。**
用户三笔手动交易全胜落在随机期望之内。目前全品种停用，只做前瞻台账记录。

时序约定（写错就是前视）：快照文件日 D 在 D 盘前抓，OI 是 OCC 在 **D−1 收盘后**结算的；
diff(D−1, D) 描述交易日 D−1，在 D 开盘前可读、可用于交易 D。周五收盘的 OI 周一凌晨才有。
真实可交易日由 `captured_at` → `core.clock.decision_session` 推出（盘中抓取的一律剔除）。
决策价 = 标的自身 C[D−1] 真实日线收盘，**永不使用快照里的 spot**（74% 的快照 spot 不是当天的价）。

## 3. 第一~三步（v3 定版，2026-09-02）

**共同口径**：开仓依据 = D−1 结构与收盘价；判定 = 到期日收盘；成交按组合单中价让 25% 点差；
手续费 $0.80/腿 × 4 = $3.20/笔；样本 SLV 2026-06-26~09-01，43 个可交易日，期间 SLV +9.7% 单边上涨。

- **① 选墙** `gamma.pick_sell_wall`：结构墙（±25% 内 OI 份额最大）；最大墙 ≠ 最近墙则朝现价挪一层；缓冲 <3% 退回；均 <3% 弃权。
  SLV put 覆盖 98% 破墙 0.0%，call 84% / 0.0%。
- **② 建仓**：DTE 2~4 是双赢（theta 最快 + 暴露最短：DTE2 净日均 $2.14 破 7% vs DTE14 $2.07 破 45%）；宽 2~3 档；
  「墙内 1 档免费」被逐日判定推翻（擦破又回来，3 笔全平错）→ 只卖墙上。
- **③ 出场**：只在收盘越过卖腿时平（逆势砍亏 76%，顺势零触发）；换墙即平是坏规则。
- **内在矛盾**：缓冲越厚越安全，但缓冲厚 + DTE 短 = 权利金≈0。**DTE 的最优区间隐含了缓冲条件。**

数据：`data/backtest/step2_grid.jsonl`（15,787 笔）；文档 `docs/wall_spread_3steps.md`。

## 4. 第四步：技术指标能否提示破墙（`scripts/step4_filters.py`, `step4_sweep.py`）

**为什么不能在价差回测上直接测**：最终规则格（墙上·DTE 2~4·宽 2~3·权利金≥$6.40）SLV 81 笔，
亏损 4 笔全是同一个事件（8/3、8/4 开仓，三天 +9.8%）。独立亏损 n=1。

**拆开来测**：卖方价差亏钱只有一种方式——价格在 k 天内逆向收盘走过缓冲。这只需要日线。
15 品种、20 年，问「指标状态 S 下，k 天内逆向突破缓冲 b 的概率是否与其余时候不同」。
缓冲两套：固定 %（策略实际口径）与 ATR 倍数（跨品种可比）；k=3；只测尾部状态；
单品种内不重叠子样本 + 两比例 z，族 36 → Bonferroni；不跨品种合并，只数 5 个相关簇的复现。

**基准率（k=3）**：2×ATR 缓冲下 15 品种都在 6%~10%/侧；固定 5% 下 GLD 1.4% ~ TQQQ 25%。
SLV 5% 缓冲 6.9%/8.7% **高于模块平衡率 2.9%~4.8%**。

**结果**（15 品种比值中位数 = 状态内破墙率 ÷ 基准率，5% 口径 / 2ATR 口径）：

| 指标 · 状态 | ↓put | ↑call | 读法 |
|---|---|---|---|
| ATR 5 日扩张比 ≥1.3 | 2.26 / 1.25 | 1.87 / 1.34 | 两套口径同号，5 簇全复现 → **唯一真信号** |
| ATR 分位 ≥90% | 1.94 / 0.84 | 1.61 / 0.74 | 反号 → 缩放效应（波动大所以 % 动得大），IV 已定价 |
| 布林带宽扩张 ≥1.3 | 1.07 / 0.99 | 1.13 / 1.06 | **无效**（五分位无剂量反应；参数扫描 54 格族中位 1.07） |
| RSI≤30 / StochK≤20 / 极超卖 | 1.2~1.3 / ≈1 | 1.4~2.1 / ≈1 | 反号 → 波动率代理 |
| RSI≥70 / 极超买 | 0.65 / ≈1 | 0.63~0.76 / ≈1 | 超买 = 平静上涨，三天内哪边都少动 |
| MACD 柱 | ≈1 | ≈1 | 完全无效 |

参数扫描（布林 54 格、ATR 54 格、RSI 24、随机 RSI 8）：ATR 扩张整族成立（族中位 1.44/1.20），
布林只有一格突出；随机 RSI 一年触发三分之一时间且≈1。
**没有任何一格在多数品种过 Bonferroni；证据等级是「跨簇方向复现」。**
8/3 那次真实亏损：所有指标中性，ATR 扩张比 0.98。
产物：`data/history/wall_spread/filter_test.json`, `filter_sweep.json`。

## 5. 第五步：近价局部墙有没有支撑（`scripts/step5_wall_hold.py`）

用户手动交易卖的是 1~5% 内的近墙，不是模块的结构主墙。近墙 = ≤14 天到期、±5% 内该侧累计 OI 最大档
（`gamma.local_wall`；另有 mode=nearest 取带内最近一堵）。零假设：墙只是个价位，破墙率 = 同距离任意价位的
破墙率 F_k(b)（20 年 E20 与快照同期 Ein 两套基准）。MC 双侧 p，不重叠子样本。

| 品种·侧 | O/E20 (k=1/2/3/4) | O/Ein (k=2) | 守住率 观测/随机 (k=2) |
|---|---|---|---|
| GLD put | 1.64 / 2.46* / 2.15 / 1.89 | 1.71 | 73% / 89% |
| GLD call | 1.73 / 1.47 / 1.57 / 2.08* | 1.02 | 74% / 82% |
| SLV put | 1.09 / 1.06 / 1.34 / 1.08 | 0.89 | 77% / 78% |
| SLV call | 1.45 / 1.65 / 1.76 / 0.97 | 1.06 | 67% / 80% |
| USO put | 2.16* / 1.63 / 0.93 / 1.69 | 1.28 | 74% / 84% |
| USO call | 1.60 / 1.52 / 1.78 / 1.45 | 0.84 | 60% / 74% |
| QQQ call | 1.19 / 1.47 / 1.15 / 2.04 | 1.18 | 79% / 86% |

（* p<0.05；各 57 个可交易日，QQQ 37。）对 20 年基准 32 格 30 格 O/E>1；对同期基准无一显著；
墙厚三分位无剂量反应；最近一堵墙（缓冲 0.4~0.7%）破墙 46%~65% ≈ 随机。
**结论：近墙不提供支撑。**与 9/3 对 LuxAlgo 订单块的检验结论相同（同源重合只是重复计数）。
四条腿全胜落在随机期望之内（缓冲 2~3%、持 2~4 天，随机守住率 75%~89%）。
产物：`wall_hold.json`, `wall_hold_nearest.json`。

## 6. 第六步：波动率风险溢价（`scripts/step6_vrp.py`）

VRP = 30 天 IV 指数 − 其后 21 日实现波动（年化 pp，前视对齐，复用 `vrp_history.forward_realized_vol`）。

| 品种 | 均值 | 正比例 | p5 | t（不重叠） | ATR 扩张≥1.3 时 均值 / p5 | ATR 分位≤10% 时 均值 / p5 |
|---|---|---|---|---|---|---|
| gold | +2.74 | 81% | −5.2 | 7.1 | +1.94 / −13.9 | +1.78 / −5.3 |
| silver | +4.89 | 83% | −12.6 | 4.5 | +1.00 / **−44.3** | +3.84 / −3.8 |
| spy | +3.89 | 85% | −5.7 | 8.8 | +1.54 / −43.7 | +4.47 / −1.2 |
| qqq | +3.55 | 80% | −8.5 | 6.1 | +0.30 / −33.2 | +4.20 / −3.0 |
| iwm | +4.16 | 84% | −5.2 | 7.6 | −0.25 / −54.8 | +4.16 / −2.8 |
| tlt | +1.65 | 75% | −3.3 | 8.1 | +1.89 / −10.6 | +1.42 / −3.0 |
| wti | +2.10 | 81% | −12.2 | 0.4 | +7.80 / −27.3 | +6.55 / −6.8 |
| googl (VXGOG) | +2.85 | 72% | −10.4 | 4.0 | +1.66 / −29.2 | +0.27 / −14.0 |
| aapl (VXAPL) | +4.42 | 77% | −9.1 | 6.4 | +3.50 / −16.3 | +3.99 / −5.0 |

短到期（快照 ATM IV 3~10 DTE vs 到期内实现波动，n=57）：silver **+10.6**（84% 正，t 6.9）、gold +4.1、wti +10.0、qqq +4.5。
**结论**：溢价真实、跨品种稳定、短到期更大；ATR 扩张日均值≈0、尾巴恶化 4~8 倍（Welch t 不显著，7 品种 6 个同向）；
ATR 低分位是风险调整后最好的卖方环境（优于 IV 高分位）。TQQQ 用 VXN 是指数错配，忽略。
产物：`vrp_states.json`。

## 7. 第七步：ATR 扩张预警的时效与召回（`scripts/step7_atr_filter.py`）

ATR 与墙同一时点（T−1 收盘定），无额外滞后。但破墙事件里前一日有信号的只占 5%；信号日占 3~5%，
剔除后 15 品种中位破墙率 6.8%→6.7%。SLV 81 笔真实回测 0 笔被标记，4 笔亏损决策日 ATR 扩张比 0.93/0.98。
**它是高精度低召回的尾巴标记，不是预警系统。**

## 9. 综合：策略到底是什么

```
卖哪一侧     ← 增仓层方向（顺方向；逆方向不卖）        证据：单品种 71~72%，第八步同向     待攒样本
卖多远       ← ATR 倍数（不是墙的位置）               证据：20 年基准率跨品种收敛         可用
卖多久       ← 2~7 DTE                               证据：短到期 VRP 最大               单一样本期
何时不卖     ← ATR 5 日扩张 ≥1.3                      证据：溢价≈0、尾巴 4~8×            砍尾巴非提胜率
怎么出       ← 收盘越过卖腿即平                        证据：第三步                        可用
不用的东西   ← 墙的位置当支撑、RSI/MACD/布林/随机 RSI 定方向或过滤、订单块共振
```

**当前状态**：全品种停用（`ACTIVE={"silver"}` 仅用于台账记录）；前瞻台账自 9/25 起随行记录决策日
ATR 扩张比/分位、带宽扩张比、近墙（`spread_ledger.record(context=)`），只记录不过滤。
**落地门槛**：≥50 笔台账推荐回填真实损益、破卖腿率 ≤ 按实际权利金算的平衡率；账户资金满足单笔风险 ≤10%、
最大亏损 ≤20%（$500 宽度的价差需 ≥$2,500 净值，或改用 $1~2 宽的 SLV 价差）；长桥价差不减免保证金。

## 10. 已知局限（与结论同呈）

1. 期权快照只有 57~65 个可交易日、单一样本期（金银大涨后回落）；个股 1 天。
2. 长历史检验只能测「破墙机制」，不能测「墙」；两者的联合样本在统计上不存在。
3. 跨品种高度相关（金银 0.89、QQQ/TQQQ 0.99、科技股同板块）；本报告只数簇复现，从不合并；
   簇复现不是显著性。
4. 全部结论都没过 Bonferroni；证据等级：VRP 存在（强）> ATR 扩张提示尾巴（跨簇复现）
   > 增仓层定侧（同向、不显著）> 其余（无证据）。
5. VRP 是波动率点数，不是价差损益；方向跳空、delta 敞口、对冲成本另算。
6. 参数（1.3、5 日、2×ATR、±5% 带、≤14 天）是事前定的，不是扫出来的；但扫描显示 ATR 扩张阈值/回看单调，
   不是精确值。任何阈值进模块前须再过前瞻台账。
7. 第五步 E20 与 Ein 分歧（同期波动高于 20 年均值）说明基准选择影响结论；本报告以同期基准为准。
8. 2026-09-25 曾误报「台账 16 天零候选」（字段名用错），已更正为 7/16；记录以示流程风险。
